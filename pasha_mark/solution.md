"Паша и Марк" через анализ выигрышных и проигрышных позиций:

## **Решение на C++ (динамическое программирование)**

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;

    // win[i] = true, если позиция i выигрышная для текущего игрока
    vector<bool> win(n + 1, false);

    // win[1] = false — из 1 нет ходов (единственный делитель d=1, но d<n не выполнено)
    // win[2]: делитель 1, n-d = 1 → ведём в проигрышную позицию → win[2] = true
    // и т.д.

    for (int i = 2; i <= n; i++) {
        // Перебираем все делители d числа i, d < i
        for (int d = 1; d < i; d++) {
            if (i % d == 0) {
                int next = i - d;
                if (!win[next]) {
                    win[i] = true;
                    break;
                }
            }
        }
    }

    cout << (win[n] ? "Pasha" : "Mark") << endl;

    return 0;
}
```

## **Аналитическое решение (O(1))**

Оказывается, можно вывести простую закономерность:

```cpp
#include <iostream>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;

    // Анализ:
    // n = 1: нет ходов → Паша проигрывает → Mark
    // n = 2: ход 2→1 → Марк проигрывает → Pasha
    // n = 3: делитель 1, 3→2 (выигрышная для Марка) → все ходы ведут в выигрыш → Mark
    // n = 4: делители 1,2 → 4→2 (выигрышная) или 4→3 (проигрышная) → есть ход в проигрыш → Pasha
    // n = 5: делитель 1, 5→4 (выигрышная) → Mark
    // n = 6: делители 1,2,3 → 6→3 (проигрышная) → Pasha
    // n = 7: делитель 1, 7→6 (выигрышная) → Mark
    // n = 8: делители 1,2,4 → 8→4 (выигрышная), 8→6 (выигрышная), 8→7 (проигрышная) → Pasha
    // ...

    // Закономерность:
    // n = 1 → Mark
    // n чётное → Pasha
    // n нечётное > 1 → Mark

    if (n % 2 == 0) {
        cout << "Pasha" << endl;
    } else {
        cout << "Mark" << endl;
    }

    return 0;
}
```

---

## **Объяснение закономерности**

### **Ключевые наблюдения**

1. **Все нечётные числа `n > 1` — проигрышные для текущего игрока.**

   Почему? У нечётного числа все делители нечётные. `n - d` = нечётное - нечётное = **чётное**.
   Значит, любой ход из нечётного `n` ведёт в **чётное** число.

2. **Все чётные числа `n ≥ 2` — выигрышные для текущего игрока.**

   Почему? Можно взять `d = 1` (всегда делитель). Тогда `n - 1` — **нечётное**.
   Если `n - 1 > 1`, то оно проигрышное → выигрышный ход.
   Если `n = 2`, то `n - 1 = 1` → тоже проигрышная позиция.

3. **`n = 1` — проигрышная** (нет ходов).

### **Индукция**

- База: `n = 1` — проигрышная.
- `n = 2` — выигрышная (ход в 1).
- `n = 3` — все ходы в чётное (в 2), а 2 выигрышное → 3 проигрышное.
- `n = 4` — есть ход в 3 (проигрышное) → выигрышное.
- ...

**Итог:** все чётные — выигрышные, все нечётные — проигрышные.

## **Проверка на примерах**

| n | Делители `d < n` | Ходы `n-d` | Результат |
|---|------------------|------------|-----------|
| 1 | нет | — | **Mark** |
| 2 | 1 | 1 (проигр.) | **Pasha** |
| 3 | 1 | 2 (выигр.) | **Mark** |
| 4 | 1, 2 | 3 (проигр.), 2 (выигр.) | **Pasha** |
| 5 | 1 | 4 (выигр.) | **Mark** |
| 6 | 1, 2, 3 | 5, 4, 3 (проигр.) | **Pasha** |
| 7 | 1 | 6 (выигр.) | **Mark** |
| 8 | 1, 2, 4 | 7 (проигр.), 6, 4 | **Pasha** |
| 9 | 1, 3 | 8, 6 (оба выигр.) | **Mark** |
| 10 | 1, 2, 5 | 9 (проигр.), 8, 5 | **Pasha** |

Закономерность подтверждается:
- **n чётное → Pasha**
- **n нечётное → Mark**

## **Почему DP тоже работает**

DP-решение перебирает все делители для каждого `i` от 2 до `n`:
- Внешний цикл: O(n)
- Внутренний цикл: O(i) для перебора делителей
- Итого: O(n²) = 10^8 при n = 10000 — работает, но медленнее.

Можно ускорить, перебирая только делители:

```cpp
for (int d = 1; d * d <= i; d++) {
    if (i % d == 0) {
        if (!win[i - d]) { win[i] = true; break; }
        int d2 = i / d;
        if (d2 != d && d2 < i && !win[i - d2]) { win[i] = true; break; }
    }
}
```

Но всё равно O(n√n) — медленнее, чем O(1).

Или через DP (если хотите показать общий подход):

```cpp
#include <iostream>
#include <vector>
using namespace std;

int main() {
    ios_base::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;

    vector<bool> win(n + 1, false);

    for (int i = 2; i <= n; i++) {
        for (int d = 1; d * d <= i; d++) {
            if (i % d == 0) {
                if (!win[i - d]) { win[i] = true; break; }
                int d2 = i / d;
                if (d2 != d && d2 < i && !win[i - d2]) { win[i] = true; break; }
            }
        }
    }

    cout << (win[n] ? "Pasha" : "Mark") << "\n";

    return 0;
}
```

| Подход | Время | Память |
|--------|-------|--------|
| **Аналитический** | O(1) | O(1) |
| **DP** | O(n√n) | O(n) |

Аналитическое решение — оптимальное: за константное время и память.

## **Итог**

- **`n` чётное** → Паша выигрывает.
- **`n` нечётное** → Марк выигрывает.

Это следует из того, что:
- Из нечётного числа любой ход ведёт в чётное.
- Из чётного числа есть ход в нечётное (взять `d = 1`).
- `n = 1` — проигрышная позиция.

Игра симметрична и решается за O(1). ✅
