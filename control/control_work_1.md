# Практическая работа: «IP-адресация и настройка сети в ОС Linux»

**Цель работы:** Научиться определять IP-адреса, маски подсети, вычислять адрес сети и диапазон хостов, а также познакомиться с базовыми сетевыми командами Linux.

**Время выполнения:** 90 минут.

**Оборудование:** Компьютер с ОС Linux (можно использовать Live-USB или виртуальную машину) без доступа в интернет.

**Программное обеспечение:** Терминал, текстовый редактор (Gedit, Mousepad, nano или любой другой).

## Ход работы

### Часть 1. Разминка (10 минут)
**Задание:** откройте терминал (Ctrl+Alt+T) и выполните команды, запишите вывод в отчёт.

1. `hostname -I` – посмотреть текущие IP-адреса компьютера.
2. `ip a` – посмотреть все сетевые интерфейсы.
3. Найдите строку, начинающуюся с `lo:` (это петлевой интерфейс). Запишите его IP-адрес (обычно `127.0.0.1`).

**Вопрос для размышления (записать в отчёт):**
Почему адрес `127.0.0.1` называют «localhost»? Что он означает?

### Часть 2. Работа с маской подсети (20 минут)

**Теория:** IP-адрес состоит из 4 байт (например, 192.168.1.10). Маска подсети показывает, какая часть адреса относится к сети, а какая — к хосту.

**Задание:**
1. В терминале выполните:
   `ipcalc 192.168.1.10/24`
   (Если команда `ipcalc` не установлена, установите её через `sudo apt install ipcalc` или используйте `sipcalc` или вручную запишите расчёт).

2. Из вывода команды выпишите в отчёт:
   - Адрес сети (Network)
   - Маску подсети (Netmask)
   - Диапазон возможных IP-адресов для хостов (HostMin – HostMax)

3. Вручную (на бумаге или в файле отчёта) переведите маску `/24` в десятичный вид и объясните, сколько хостов может быть в такой сети.

**Результат:** таблица в вашем отчёте.

## Работа с маской подсети (20 минут)

**Теория:**
IP-адрес (например, `192.168.1.10`) состоит из 4 октетов (байт).
Маска подсети определяет границу между **сетевой** и **хостовой** частью.
- Если бит в маске = 1 — это часть сети.
- Если бит в маске = 0 — это часть хоста.

Краткая запись маски через `/` называется **префиксом** (например, `/24` означает 24 единичных бита).

---

### Задание 2.1. Базовый расчёт (обязательное)

Выполните в терминале (или рассчитайте вручную):

```bash
ipcalc 192.168.1.10/24
```

**Выпишите в отчёт:**
1. Адрес сети (Network)
2. Маску подсети в десятичном виде (Netmask)
3. Широковещательный адрес (Broadcast)
4. Диапазон хостов (HostMin – HostMax)
5. Количество доступных хостов (формула: 2^(32-префикс) – 2)

**Дополнительный вопрос:**
Почему из общего числа адресов вычитается 2? Какой адрес теряется, а какой резервируется?

---

### Задание 2.2. Работа с разными масками (обязательное)

Для каждого из приведённых IP-адресов выполните расчёт (можно использовать `ipcalc` или ручной подсчёт). Заполните таблицу в отчёте:

| IP-адрес         | Префикс | Адрес сети | Маска (десятичная) | Кол-во хостов | Первый хост | Последний хост |
|------------------|---------|------------|---------------------|---------------|-------------|----------------|
| 10.0.0.5         | /8      |            |                     |               |             |                |
| 172.16.1.100     | /16     |            |                     |               |             |                |
| 192.168.0.1      | /25     |            |                     |               |             |                |
| 203.0.113.7      | /30     |            |                     |               |             |                |

**Для справки (префиксы и маски):**
- `/8`  → 255.0.0.0
- `/16` → 255.255.0.0
- `/24` → 255.255.255.0
- `/25` → 255.255.255.128
- `/30` → 255.255.255.252

### Задание 2.4. Практический кейс (необязательное, но полезное)

**Задача:**
Вам нужно спроектировать подсеть для офиса, в котором работает **50 компьютеров**.
Какую минимальную маску (префикс) вы выберете, чтобы все компьютеры получили уникальные IP-адреса и остался запас на 10 новых машин в будущем?

**План действий:**
1. Определите необходимое количество адресов (с учётом запаса).
2. Подберите минимальную степень двойки, которая покрывает это число.
3. Рассчитайте префикс.
4. Запишите маску в десятичном виде.
5. Приведите пример адреса сети (можно взять `10.10.0.0` с этой маской).

**Запишите в отчёт** полное решение с пояснениями.

### Задание 2.5. Сравнительный анализ (для самых быстрых)

Сравните две сети:
- Сеть A: `192.168.1.0/24`
- Сеть B: `192.168.1.0/25`

Ответьте на вопросы:

3. В какой сети адрес `192.168.1.130` будет допустим для хоста?
