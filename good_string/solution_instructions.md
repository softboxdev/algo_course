## **Постановка задачи (коротко)**
У нас есть строка.
Мы можем удалять две **соседние** буквы, если:
- это **одна и та же буква** (например, `a` и `A`, `b` и `B`, `Z` и `z`);
- но они **записаны в разных регистрах** (одна заглавная, другая строчная).

После удаления строка «схлопывается» — пробелов не остаётся, соседние символы сдвигаются.

Наша цель — **применить такие удаления**, пока это возможно, и получить «хорошую» строку (в которой уже нет таких пар).

---

## **Почему стек?**
Когда мы удаляем пару, символы **слева** от неё становятся соседними с символами **справа**.
Это значит, что после удаления может образоваться **новая пара**, которую тоже надо удалить.

Пример:
`a A b B`
- Удаляем `a A` → остаётся `b B`
- Теперь `b` и `B` стали соседями → удаляем их → строка пуста.

Стек отлично подходит, потому что мы:
- проходим по строке слева направо;
- кладём символы в стек;
- если новый символ «удаляется» с верхушкой стека — выталкиваем верхушку (то есть удаляем пару).

## **Решение 1: с использованием `std::vector` как стека**

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <cstdlib>  // для abs()

using namespace std;

string convertToGoodString(const string& probablyBadString) {
    vector<char> stack;

    for (char ch : probablyBadString) {
        // Проверяем, образует ли текущий символ пару с верхушкой стека
        if (!stack.empty() && abs(stack.back() - ch) == 32) {
            // Если образует - удаляем верхушку стека (оба символа исчезают)
            stack.pop_back();
        } else {
            // Если не образует - добавляем текущий символ в стек
            stack.push_back(ch);
        }
    }

    // Превращаем стек в строку
    string result;
    for (char ch : stack) {
        result.push_back(ch);
    }
    return result;
}

int main() {
    string probablyBadString;
    cin >> probablyBadString;
    cout << convertToGoodString(probablyBadString);
    return 0;
}
```

## **Решение 3: с использованием `std::stack` из STL**

```cpp
#include <iostream>
#include <string>
#include <stack>
#include <algorithm>  // для reverse()

using namespace std;

string convertToGoodString(const string& probablyBadString) {
    stack<char> st;

    for (char ch : probablyBadString) {
        // Проверяем, образует ли текущий символ пару с верхушкой стека
        if (!st.empty() && abs(st.top() - ch) == 32) {
            // Если образует - удаляем верхушку стека (оба символа исчезают)
            st.pop();
        } else {
            // Если не образует - добавляем текущий символ в стек
            st.push(ch);
        }
    }

    // Перекладываем из стека в строку (в обратном порядке)
    string result;
    while (!st.empty()) {
        result.push_back(st.top());
        st.pop();
    }
    reverse(result.begin(), result.end());  // разворачиваем обратно
    return result;
}

int main() {
    string probablyBadString;
    cin >> probablyBadString;
    cout << convertToGoodString(probablyBadString);
    return 0;
}
```

Разберём по частям:

- `!stack.empty()` — **стек не пустой**. Если стек пуст, то не с чем сравнивать, и мы просто добавляем символ.
- `stack.back()` — **последний символ** в стеке (верхушка стека). Это тот символ, который лежит прямо перед текущим `ch` в исходной строке (после всех предыдущих удалений).

**Почему 32?**
В таблице ASCII:
- `'a'` = 97, `'A'` = 65 → разница 32
- `'b'` = 98, `'B'` = 66 → разница 32
- и так для всех букв.

Если разность равна 32, значит:
- один символ — заглавный, другой — строчный,
- и это **одна и та же буква**.

Значит, они образуют пару, которую можно удалить.

## **Как происходит удаление на примере**

Возьмём строку: `aAbB`

| Шаг | Текущий символ | Стек до | Проверка | Действие | Стек после |
|-----|---------------|---------|----------|----------|------------|
| 1   | `a`           | []      | стек пуст | добавить | `[a]`      |
| 2   | `A`           | `[a]`   | `a` и `A` — разница 32 → пара | удалить `a` | `[]` |
| 3   | `b`           | `[]`    | стек пуст | добавить | `[b]`      |
| 4   | `B`           | `[b]`   | `b` и `B` — разница 32 → пара | удалить `b` | `[]` |

Результат: пустая строка (вывод ничего не выведет).

---

### Ещё пример: `vxOoOoVvx`

Разберём быстрее:

| Символ | Действие | Стек после |
|--------|----------|------------|
| v      | добавить | [v]        |
| x      | добавить | [v, x]     |
| O      | добавить | [v, x, O]  |
| o      | O и o — пара → удалить O | [v, x]     |
| O      | добавить | [v, x, O]  |
| o      | O и o — пара → удалить O | [v, x]     |
| V      | x и V — не пара (буквы разные) → добавить | [v, x, V]  |
| v      | V и v — пара → удалить V | [v, x]     |
| x      | x и x — не пара (регистр не разный) → добавить | [v, x, x]  |

Итог: `vxx` — что и требовалось.

## **Почему это гарантирует хорошую строку?**
Цикл проверяет **каждую возможную пару** в порядке появления.
Когда мы удаляем пару, мы **заново** проверяем новый верхний символ со следующим.
В конце в стеке не остаётся ни одной пары, которую можно удалить, значит строка хорошая.

## **Основные операции со стеком в C++**

### 1. **`empty()`** — проверка на пустоту
```cpp
stack.empty()
```
- **Что делает:** Проверяет, пуст ли стек.
- **Возвращает:** `true` (если стек пуст) или `false` (если в стеке есть элементы).
- **Зачем:** Чтобы не пытаться обратиться к последнему элементу, когда стек пуст.
- **В нашем коде:** `!stack.empty()` — проверяем, что стек не пуст, прежде чем сравнивать символы.

---

### 2. **`back()`** — доступ к последнему элементу
```cpp
stack.back()
```
- **Что делает:** Возвращает ссылку на **последний** добавленный элемент (верхушку стека), но **НЕ удаляет** его.
- **Зачем:** Чтобы посмотреть, с чем мы будем сравнивать текущий символ.
- **В нашем коде:** `stack.back()` — берём последний символ из стека для сравнения с текущим `ch`.

---

### 3. **`push_back()`** — добавление элемента
```cpp
stack.push_back(ch)
```
- **Что делает:** Добавляет новый элемент **в конец** стека (на вершину).
- **Зачем:** Кладём символ в стек, чтобы он мог позже образовать пару со следующим символом.
- **В нашем коде:** `stack.push_back(ch)` — добавляем текущий символ, если пара не найдена.

---

### 4. **`pop_back()`** — удаление последнего элемента
```cpp
stack.pop_back()
```
- **Что делает:** Удаляет **последний** элемент из стека (с вершины). Ничего не возвращает.
- **Зачем:** Убираем символ, который образовал пару с текущим.
- **В нашем коде:** `stack.pop_back()` — удаляем верхушку стека, так как она образует пару с `ch`.

---

### 5. **`size()`** — количество элементов (не используется, но полезно знать)
```cpp
stack.size()
```
- **Что делает:** Возвращает количество элементов в стеке.
- **Зачем:** Может пригодиться для отладки или дополнительных проверок.
- **В нашем коде:** Не используется, но можно было бы проверить размер после обработки.

## **Все операции в контексте алгоритма**

Посмотрим на полный код и отметим каждую операцию:

```cpp
#include <iostream>
#include <string>
#include <vector>

int main() {
    std::string s;
    std::cin >> s;

    std::vector<char> stack;  // ← создание стека (пустой)

    for (char ch : s) {
        // 1. ОПЕРАЦИЯ: empty() — проверка на пустоту
        // 2. ОПЕРАЦИЯ: back() — получение последнего элемента
        if (!stack.empty() && abs(stack.back() - ch) == 32) {

            // 3. ОПЕРАЦИЯ: pop_back() — удаление последнего элемента
            stack.pop_back();  // удаляем верхушку стека

        } else {
            // 4. ОПЕРАЦИЯ: push_back() — добавление элемента
            stack.push_back(ch);  // кладём текущий символ в стек
        }
    }

    // Вывод результата (здесь операций со стеком нет)
    for (char ch : stack) {
        std::cout << ch;
    }
    std::cout << std::endl;

    return 0;
}
```

## **Альтернативная реализация с `std::stack`**

Если использовать стандартный стек из STL:

```cpp
#include <iostream>
#include <string>
#include <stack>

int main() {
    std::string s;
    std::cin >> s;

    std::stack<char> st;  // ← создание стека

    for (char ch : s) {
        if (!st.empty() && abs(st.top() - ch) == 32) {
            st.pop();  // ← удаление верхушки
        } else {
            st.push(ch);  // ← добавление элемента
        }
    }

    // Для вывода нужно переложить в строку (так как stack не имеет итераторов)
    std::string result;
    while (!st.empty()) {
        result += st.top();
        st.pop();
    }
    std::reverse(result.begin(), result.end());
    std::cout << result << std::endl;

    return 0;
}
```

Здесь операции называются:
- `top()` — вместо `back()`
- `pop()` — вместо `pop_back()`
- `push()` — вместо `push_back()`

## **Итоговый список операций со стеком**

1. **`empty()`** — проверка пустоты
2. **`back()` / `top()`** — просмотр верхушки
3. **`push_back()` / `push()`** — добавление элемента
4. **`pop_back()` / `pop()`** — удаление верхушки
5. **`size()`** — получение размера (дополнительно)

Это все основные операции, которые нужны для решения данной задачи!


### Альтернативное решение с использованием `std::string` как стека:

```cpp
#include <iostream>
#include <string>

int main() {
    std::string s;
    std::cin >> s;

    std::string result;

    for (char ch : s) {
        if (!result.empty() && abs(result.back() - ch) == 32) {
            result.pop_back();
        } else {
            result.push_back(ch);
        }
    }

    std::cout << result << std::endl;

    return 0;
}
```

### Пояснение:
- Используем `abs(stack.back() - ch) == 32` для проверки, что символы — это одна и та же буква в разных регистрах (разница в ASCII кодах равна 32).
- Если условие выполняется, удаляем последний символ из стека (удаляем пару).
- Иначе добавляем текущий символ в стек.
- В конце стек содержит результирующую хорошую строку.
