Пошаговая инструкция по установке Git и генерации SSH-ключей в ОС ROSA.

### 🛠️ Шаг 1: Установка Git

1.  Откройте терминал.
2.  Обновите список пакетов и установите Git. Для ОС семейства ROSA, которая основана на Red Hat, используйте менеджер пакетов `dnf`:
    ```bash
    sudo dnf install -y git
    ```
    > **Примечание:** Если ваша версия ROSA использует `yum`, команда будет `sudo yum install -y git`.

3.  Проверьте успешность установки, чтобы увидеть версию Git:
    ```bash
    git --version
    ```

### ⚙️ Шаг 2: Базовая настройка Git

Настройте ваше имя пользователя и email. Эти данные будут привязаны к вашим коммитам.

```bash
git config --global user.name "Ваше Имя"
git config --global user.email "ваш.email@example.com"
```
Чтобы проверить все настройки, выполните:
```bash
git config --list
```

### 🔑 Шаг 3: Генерация SSH-ключа


```bash
# 1. Перейдите в домашнюю директорию
cd ~

# 2. Удалите старые ключи (если есть)
rm -f ~/.ssh/id_ed25519*

# 3. Создайте директорию с правильными правами
mkdir -p ~/.ssh
chmod 700 ~/.ssh

# 4. Сгенерируйте ключ (БЕЗ sudo!)
ssh-keygen -t ed25519 -C "soft.box.development@gmail.com"
# Просто нажимайте Enter на все вопросы

# 5. Проверьте, что файлы созданы
ls -la ~/.ssh/
# Должны увидеть id_ed25519 и id_ed25519.pub с владельцем user

# 6. Запустите ssh-agent
eval "$(ssh-agent -s)"

# 7. Добавьте ключ
ssh-add ~/.ssh/id_ed25519

# 8. Посмотрите публичный ключ
cat ~/.ssh/id_ed25519.pub
```

## 🔍 Проверьте владельца и права файла

```bash
ls -la ~/.ssh/
```

## 🔧 В случае ошибок с правами: Исправьте владельца и права

```bash
# Измените владельца на user (если файл принадлежит root)
sudo chown -R user:user ~/.ssh/

# Установите правильные права доступа
chmod 700 ~/.ssh/
chmod 600 ~/.ssh/id_ed25519
chmod 644 ~/.ssh/id_ed25519.pub
```

## 🔑 В случае ошибок с ключами: Если ключ еще не создан, создайте его заново

```bash
# Удалите старые ключи, если они есть
rm -f ~/.ssh/id_ed25519*

# Создайте новый ключ
ssh-keygen -t ed25519 -C "soft.box.development@gmail.com"
# На все вопросы просто нажимайте Enter

# Проверьте права
ls -la ~/.ssh/
```

## 🚨 Если ничего не помогает - полная переустановка

```bash
# 1. Удалите всю папку .ssh
rm -rf ~/.ssh/

# 2. Создайте заново
mkdir ~/.ssh
chmod 700 ~/.ssh

# 3. Сгенерируйте ключи
ssh-keygen -t ed25519 -C "soft.box.development@gmail.com"

# 4. Проверьте
ls -la ~/.ssh/
# Вы должны увидеть:
# -rw------- 1 user user ... id_ed25519
# -rw-r--r-- 1 user user ... id_ed25519.pub

# 5. Запустите ssh-agent и добавьте ключ
eval "$(ssh-agent -s)"
ssh-add ~/.ssh/id_ed25519

# 6. Проверьте работу
ssh -T git@github.com
```

## ⚠️ Важно:
- **Никогда не используйте `sudo`** при работе с SSH-ключами от имени обычного пользователя
- Всегда проверяйте, что вы находитесь в правильной директории: `pwd` должно показывать `/home/user`
- Убедитесь, что файлы принадлежат `user`, а не `root`
