## Теоретическая часть

### Что такое кортеж?

**Кортеж (tuple)** — это упорядоченная **неизменяемая** коллекция элементов в Python.

**Ключевые свойства:**
- **Неизменяемый** — после создания кортежа нельзя изменить, добавить или удалить элементы.
- **Упорядоченный** — элементы хранятся в определённом порядке.
- **Индексируемый** — доступ к элементам по индексу (с 0).
- **Итерируемый** — можно перебирать в цикле.
- **Хешируемый** — если все элементы кортежа хешируемы, то и сам кортеж хешируем, а значит, **может быть ключом в dict**.

**Синтаксис:**
```python
t = (1, 2, 3)          # кортеж из трёх элементов
t = 1, 2, 3            # без скобок (тоже кортеж)
t = ()                 # пустой кортеж
t = (5,)               # кортеж из одного элемента (обязательна запятая!)
```

**Сравнение с list:**

| Характеристика | list | tuple |
|----------------|------|-------|
| Изменяемость | Да | Нет |
| Скорость | Медленнее | Быстрее |
| Память | Больше | Меньше |
| Ключ в dict | Нет | Да |
| Синтаксис | `[1, 2, 3]` | `(1, 2, 3)` |

### Задание 1. Создание кортежа и доступ к элементам

**Код с подробным объяснением:**

```python
# Создаём кортеж с именем coordinates
coordinates = (10, 20, 30)
# coordinates — имя переменной (идентификатор)
# = — оператор присваивания
# ( — открывающая скобка кортежа
# 10 — первый элемент (целое число)
# , — разделитель элементов
# 20 — второй элемент
# , — разделитель
# 30 — третий элемент
# ) — закрывающая скобка кортежа
# Вся строка — инструкция присваивания кортежа переменной

# Получаем первый элемент кортежа
first = coordinates[0]
# first — имя переменной для хранения результата
# = — оператор присваивания
# coordinates — имя кортежа
# [ — открывающая квадратная скобка для индексации
# 0 — индекс первого элемента (нумерация с нуля)
# ] — закрывающая квадратная скобка
# Результат: first = 10

# Получаем последний элемент кортежа
last = coordinates[-1]
# last — имя переменной
# = — присваивание
# coordinates — кортеж
# [ — индексация
# -1 — отрицательный индекс (последний элемент)
# ] — закрывающая скобка
# Результат: last = 30

# Получаем длину кортежа
length = len(coordinates)
# length — имя переменной
# = — присваивание
# len — встроенная функция (length — длина)
# ( — открывающая скобка вызова функции
# coordinates — аргумент функции
# ) — закрывающая скобка
# Результат: length = 3

# Выводим результаты на экран
print(first, last, length)
# print — встроенная функция вывода
# ( — открывающая скобка
# first — первый аргумент (10)
# , — разделитель аргументов
# last — второй аргумент (30)
# , — разделитель
# length — третий аргумент (3)
# ) — закрывающая скобка
# Результат на экране: 10 30 3
```

**Результат выполнения:**
```
10 30 3
```

### Задание 2. Демонстрация неизменяемости кортежа

**Код с комментариями:**

```python
# Создаём кортеж
point = (5, 10)
# point — имя переменной
# = — присваивание
# (5, 10) — кортеж из двух элементов

# Пытаемся изменить первый элемент
point[0] = 100
# point — имя кортежа
# [0] — индекс первого элемента
# = — оператор присваивания
# 100 — новое значение
# ЭТА СТРОКА ВЫЗОВЕТ ОШИБКУ: TypeError: 'tuple' object does not support item assignment
# Потому что кортеж неизменяемый!

# Правильный способ "изменения" — создать новый кортеж
new_point = (100,) + point[1:]
# new_point — имя новой переменной
# = — присваивание
# ( — открывающая скобка
# 100 — новый первый элемент
# , — запятая (обязательна для кортежа из одного элемента!)
# ) — закрывающая скобка — получили кортеж (100,)
# + — оператор конкатенации (склеивания) кортежей
# point — исходный кортеж
# [1:] — срез от индекса 1 до конца (элементы 10)
# Результат: new_point = (100, 10)

# Выводим новый кортеж
print(new_point)
# print — функция вывода
# (new_point) — аргумент
# Результат: (100, 10)
```

**Результат выполнения:**
```
TypeError: 'tuple' object does not support item assignment
(100, 10)
```

**Вывод:** кортеж нельзя изменить, но можно создать новый на основе старого.

### Задание 3. Использование кортежа как ключа словаря

**Код с комментариями:**

```python
# Создаём словарь, где ключи — кортежи
matrix = {}
# matrix — имя переменной для словаря
# = — присваивание
# { — открывающая фигурная скобка словаря
# } — закрывающая фигурная скобка (пустой словарь)

# Добавляем элемент: ключ — кортеж (0, 0), значение — 1
matrix[(0, 0)] = 1
# matrix — имя словаря
# [ — открывающая квадратная скобка для доступа по ключу
# ( — открывающая скобка кортежа-ключа
# 0 — первый элемент ключа
# , — разделитель
# 0 — второй элемент ключа
# ) — закрывающая скобка кортежа
# ] — закрывающая квадратная скобка
# = — оператор присваивания
# 1 — значение, которое сохраняем по этому ключу
# Результат: matrix = {(0, 0): 1}

# Добавляем ещё один элемент
matrix[(1, 2)] = 5
# matrix — словарь
# [(1, 2)] — ключ-кортеж из двух элементов
# = — присваивание
# 5 — значение
# Результат: matrix = {(0, 0): 1, (1, 2): 5}

# Получаем значение по ключу-кортежу
value = matrix[(0, 0)]
# value — имя переменной
# = — присваивание
# matrix — словарь
# [(0, 0)] — ключ-кортеж
# Результат: value = 1

# Выводим значение
print(value)
# print — функция вывода
# (value) — аргумент
# Результат: 1
```

**Результат выполнения:**
```
1
```

**Почему это работает?** Кортеж хешируем (если все его элементы хешируемы), поэтому может быть ключом словаря. Список — не хешируем, поэтому ключом быть не может.

**Проверка (ошибка со списком):**
```python
d = {}
d[[1, 2]] = 5
# TypeError: unhashable type: 'list'
```

### Задание 4. Сравнение скорости и памяти: tuple vs list

**Код с комментариями:**

```python
# Импортируем модуль для измерения размера объектов
import sys
# import — ключевое слово для подключения модуля
# sys — имя модуля (system — системный)
# Модуль sys содержит функцию getsizeof для измерения размера объекта

# Создаём список из 5 элементов
my_list = [1, 2, 3, 4, 5]
# my_list — имя переменной
# = — присваивание
# [ — открывающая квадратная скобка списка
# 1, 2, 3, 4, 5 — элементы списка
# ] — закрывающая квадратная скобка

# Создаём кортеж из тех же 5 элементов
my_tuple = (1, 2, 3, 4, 5)
# my_tuple — имя переменной
# = — присваивание
# ( — открывающая скобка кортежа
# 1, 2, 3, 4, 5 — элементы кортежа
# ) — закрывающая скобка

# Измеряем размер списка в байтах
size_list = sys.getsizeof(my_list)
# size_list — имя переменной для результата
# = — присваивание
# sys — модуль
# . — оператор доступа к атрибуту модуля
# getsizeof — функция измерения размера
# ( — открывающая скобка вызова
# my_list — аргумент (список)
# ) — закрывающая скобка
# Результат: size_list ≈ 104 байта

# Измеряем размер кортежа в байтах
size_tuple = sys.getsizeof(my_tuple)
# size_tuple — имя переменной
# = — присваивание
# sys.getsizeof — функция измерения размера
# (my_tuple) — аргумент (кортеж)
# Результат: size_tuple ≈ 80 байт

# Выводим результаты
print("Размер списка:", size_list, "байт")
# print — функция вывода
# "Размер списка:" — строковый литерал (текст)
# , — разделитель аргументов
# size_list — значение переменной
# , — разделитель
# "байт" — строковый литерал
# Результат: Размер списка: 104 байт

print("Размер кортежа:", size_tuple, "байт")
# print — функция вывода
# "Размер кортежа:" — текст
# size_tuple — значение
# "байт" — текст
# Результат: Размер кортежа: 80 байт

# Вычисляем экономию памяти
saving = size_list - size_tuple
# saving — имя переменной (экономия)
# = — присваивание
# size_list — размер списка
# - — оператор вычитания
# size_tuple — размер кортежа
# Результат: saving = 24 байта

print("Экономия:", saving, "байт")
# print — функция вывода
# "Экономия:" — текст
# saving — значение
# "байт" — текст
# Результат: Экономия: 24 байт
```

**Результат выполнения:**
```
Размер списка: 104 байт
Размер кортежа: 80 байт
Экономия: 24 байт
```

**Вывод:** кортеж занимает меньше памяти, чем список с теми же элементами.

### Задание 5. Распаковка кортежа (unpacking)

**Код с комментариями:**

```python
# Создаём кортеж с координатами точки
point = (3, 7)
# point — имя переменной
# = — присваивание
# (3, 7) — кортеж из двух элементов

# Распаковываем кортеж в две переменные
x, y = point
# x — имя первой переменной
# , — разделитель переменных
# y — имя второй переменной
# = — присваивание
# point — кортеж, который распаковываем
# Результат: x = 3, y = 7

# Выводим значения
print("x =", x, "y =", y)
# print — функция вывода
# "x =" — текст
# x — значение (3)
# "y =" — текст
# y — значение (7)
# Результат: x = 3 y = 7

# Распаковка с игнорированием элементов через _
a, _, c = (10, 20, 30)
# a — первая переменная (10)
# _ — соглашение об игнорировании (сюда попадёт 20)
# c — третья переменная (30)
# Результат: a = 10, c = 30 (20 игнорируется)

print(a, c)
# print — функция вывода
# a — значение (10)
# c — значение (30)
# Результат: 10 30

# Распаковка с * (звёздочкой) — сбор оставшихся элементов в список
first, *rest = (1, 2, 3, 4, 5)
# first — первая переменная (1)
# *rest — звёздочка означает "собрать всё оставшееся в список"
# rest — имя переменной для списка [2, 3, 4, 5]
# Результат: first = 1, rest = [2, 3, 4, 5]

print(first, rest)
# print — функция вывода
# first — значение (1)
# rest — список [2, 3, 4, 5]
# Результат: 1 [2, 3, 4, 5]
```

**Результат выполнения:**
```
x = 3 y = 7
10 30
1 [2, 3, 4, 5]
```

### Задание 6. Возврат нескольких значений из функции через кортеж

**Код с комментариями:**

```python
# Определяем функцию, возвращающую min и max
def min_max(numbers):
# def — ключевое слово для определения функции
# min_max — имя функции
# ( — открывающая скобка параметров
# numbers — параметр функции (список чисел)
# ) — закрывающая скобка
# : — двоеточие, начало тела функции

    # Находим минимум
    minimum = min(numbers)
    # minimum — имя переменной
    # = — присваивание
    # min — встроенная функция поиска минимума
    # (numbers) — аргумент функции
    
    # Находим максимум
    maximum = max(numbers)
    # maximum — имя переменной
    # = — присваивание
    # max — встроенная функция поиска максимума
    # (numbers) — аргумент
    
    # Возвращаем кортеж из двух значений
    return minimum, maximum
    # return — ключевое слово возврата значения
    # minimum — первое возвращаемое значение
    # , — разделитель (Python автоматически создаёт кортеж)
    # maximum — второе возвращаемое значение
    # Фактически возвращается кортеж (minimum, maximum)

# Вызываем функцию и распаковываем результат
lo, hi = min_max([4, 1, 9, 3, 7])
# lo — имя переменной для минимума
# , — разделитель
# hi — имя переменной для максимума
# = — присваивание
# min_max — имя функции
# ([4, 1, 9, 3, 7]) — аргумент-список
# Результат: lo = 1, hi = 9

# Выводим результаты
print("Минимум:", lo, "Максимум:", hi)
# print — функция вывода
# "Минимум:" — текст
# lo — значение (1)
# "Максимум:" — текст
# hi — значение (9)
# Результат: Минимум: 1 Максимум: 9
```

**Результат выполнения:**
```
Минимум: 1 Максимум: 9
```

### Задание 7. Практическая задача: подсчёт частоты слов с использованием кортежей

**Условие:** дана строка. Найти топ-3 самых частых слова.

**Код с комментариями:**

```python
# Исходная строка
text = "кот пёс кот кот пёс птица кот птица"
# text — имя переменной
# = — присваивание
# "..." — строковый литерал

# Разбиваем строку на слова
words = text.split()
# words — имя переменной для списка слов
# = — присваивание
# text — исходная строка
# . — оператор доступа к методу
# split — метод разбиения строки по пробелам
# () — вызов метода без аргументов
# Результат: words = ['кот', 'пёс', 'кот', 'кот', 'пёс', 'птица', 'кот', 'птица']

# Создаём пустой словарь для подсчёта частот
freq = {}
# freq — имя переменной (frequency — частота)
# = — присваивание
# {} — пустой словарь

# Перебираем все слова
for word in words:
# for — ключевое слово цикла
# word — переменная-итератор (текущее слово)
# in — ключевое слово принадлежности
# words — список слов
# : — двоеточие, начало тела цикла

    # Увеличиваем счётчик для слова
    freq[word] = freq.get(word, 0) + 1
    # freq — словарь
    # [word] — ключ (текущее слово)
    # = — присваивание
    # freq.get — метод получения значения по ключу
    # (word, 0) — аргументы: ключ и значение по умолчанию (0)
    # + 1 — увеличиваем на 1
    # Если слова нет в словаре — вернёт 0, прибавит 1 = 1
    # Если есть — вернёт текущее значение, прибавит 1

# Преобразуем словарь в список кортежей (слово, частота)
items = list(freq.items())
# items — имя переменной
# = — присваивание
# list — встроенная функция преобразования в список
# ( — открывающая скобка
# freq.items — метод словаря, возвращающий пары (ключ, значение)
# () — вызов метода
# ) — закрывающая скобка
# Результат: items = [('кот', 4), ('пёс', 2), ('птица', 2)]

# Сортируем список кортежей по частоте (по убыванию)
items.sort(key=lambda pair: pair[1], reverse=True)
# items — список кортежей
# .sort — метод сортировки списка (на месте)
# ( — открывающая скобка
# key= — именованный аргумент "ключ сортировки"
# lambda — ключевое слово для анонимной функции
# pair — параметр лямбды (элемент списка — кортеж)
# : — двоеточие, начало тела лямбды
# pair[1] — второй элемент кортежа (частота)
# , — разделитель аргументов
# reverse=True — сортировка по убыванию
# ) — закрывающая скобка
# Результат: items = [('кот', 4), ('пёс', 2), ('птица', 2)]

# Берём первые три элемента (топ-3)
top3 = items[:3]
# top3 — имя переменной
# = — присваивание
# items — отсортированный список
# [:3] — срез от начала до индекса 3 (не включая)
# Результат: top3 = [('кот', 4), ('пёс', 2), ('птица', 2)]

# Выводим топ-3
print("Топ-3 частых слов:")
# print — функция вывода
# "Топ-3 частых слов:" — текст

for word, count in top3:
# for — цикл
# word — переменная для первого элемента кортежа
# , — разделитель
# count — переменная для второго элемента кортежа
# in — принадлежность
# top3 — список кортежей
# : — двоеточие
# Здесь происходит распаковка каждого кортежа в две переменные

    print(f"  {word}: {count}")
    # print — функция вывода
    # f"..." — f-строка (форматированная строка)
    # {word} — подстановка значения переменной word
    # : — разделитель
    # {count} — подстановка значения переменной count
    # Результат: "  кот: 4", "  пёс: 2", "  птица: 2"
```

**Результат выполнения:**
```
Топ-3 частых слов:
  кот: 4
  пёс: 2
  птица: 2
```
