## Краткая справка (повторение перед работой)

**Список (`list`)** — упорядоченная **изменяемая** коллекция элементов.

```python
lst = [1, 2, 3]        # создание
lst.append(4)          # добавление в конец
lst[0]                 # доступ по индексу
lst[-1]                # последний элемент
len(lst)               # длина
lst.pop()              # удаление с конца
lst.pop(0)             # удаление с начала (O(n)!)
lst[1:3]               # срез
```

**Стек (`stack`)** — структура данных по принципу **LIFO** (Last In — First Out).

```python
stack = []             # создание
stack.append(5)        # push: добавить
stack[-1]              # top: посмотреть верхний
stack.pop()            # pop: извлечь верхний
len(stack) == 0        # is_empty
```

**Эффективная реализация:** `collections.deque` для больших данных.

### Задача B3. Проверка скобочной последовательности (4 балла)

**Условие:** Пользователь вводит строку, содержащую только символы `(`, `)`, `[`, `]`, `{`, `}`. Проверьте, является ли последовательность скобок **правильной**.

Правильная последовательность:
- каждая открывающая скобка имеет соответствующую закрывающую;
- скобки закрываются в правильном порядке.

**Пример ввода и вывода:**
```
Ввод: ([]{})
Вывод: Правильно

Ввод: ([)]
Вывод: Неправильно

Ввод: (((
Вывод: Неправильно
```

**Подсказка:** используйте стек и словарь соответствий `{')': '(', ']': '[', '}': '{'}`.
