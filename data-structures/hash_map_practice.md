## 1. Теоретическая часть

### 1.1. Что такое хеш-таблица?

**Хеш-таблица (hash table)** — структура данных, которая хранит пары «ключ → значение» и обеспечивает **быстрый доступ** к значению по ключу за **O(1)** в среднем.

**Принцип работы:**
1. Для ключа вычисляется **хеш-функция** — число, которое определяет «ячейку» (bucket) в таблице.
2. Значение сохраняется в этой ячейке.
3. При поиске снова вычисляется хеш — и значение находится сразу, без перебора.

**Аналогия из жизни:** шкаф с ящиками, подписанными по алфавиту. Чтобы найти книгу «Война и мир», вы идёте к ящику «В», а не перебираете все книги.

### 1.2. Реализация в Python

В Python хеш-таблицы реализованы двумя встроенными типами:

| Тип | Назначение | Синтаксис |
|-----|------------|-----------|
| `dict` (словарь) | Хранение пар «ключ → значение» | `{ключ: значение}` |
| `set` (множество) | Хранение уникальных элементов | `{элемент1, элемент2}` |

### 1.3. Словарь (`dict`)

**Основные операции:**

| Операция | Код | Сложность |
|----------|-----|-----------|
| Создание | `d = {}` или `d = dict()` | O(1) |
| Добавление/изменение | `d[key] = value` | O(1) |
| Получение | `d[key]` | O(1) |
| Безопасное получение | `d.get(key, default)` | O(1) |
| Удаление | `del d[key]` или `d.pop(key)` | O(1) |
| Проверка наличия | `key in d` | O(1) |
| Размер | `len(d)` | O(1) |
| Перебор ключей | `for k in d:` | O(n) |
| Перебор пар | `for k, v in d.items():` | O(n) |

**Важно:** ключом может быть только **хешируемый** объект — число, строка, кортеж (если все элементы хешируемы). Список — нельзя.

### 1.4. Множество (`set`)

**Основные операции:**

| Операция | Код | Сложность |
|----------|-----|-----------|
| Создание | `s = set()` или `s = {1, 2, 3}` | O(1) |
| Добавление | `s.add(x)` | O(1) |
| Удаление | `s.remove(x)` / `s.discard(x)` | O(1) |
| Проверка наличия | `x in s` | O(1) |
| Объединение | `s1 \| s2` | O(len(s1)+len(s2)) |
| Пересечение | `s1 & s2` | O(min(len(s1), len(s2))) |
| Разность | `s1 - s2` | O(len(s1)) |
| Размер | `len(s)` | O(1) |

**Отличие `remove` от `discard`:** `remove` вызывает ошибку `KeyError`, если элемента нет; `discard` — нет.

### 1.5. Сравнение с другими структурами

| Структура | Поиск | Вставка | Удаление | Упорядоченность |
|-----------|-------|---------|----------|-----------------|
| Список (`list`) | O(n) | O(1) в конец | O(n) | Да |
| Кортеж (`tuple`) | O(n) | — | — | Да |
| Словарь (`dict`) | O(1) | O(1) | O(1) | Нет (с Python 3.7 — порядок вставки) |
| Множество (`set`) | O(1) | O(1) | O(1) | Нет |

### 1.6. Применение хеш-таблиц в олимпиадном программировании

1. **Частотный анализ** — подсчёт количества вхождений элементов.
2. **Поиск дубликатов** — проверка уникальности.
3. **Группировка** — объединение элементов по ключу (анаграммы, суммы).
4. **Кеширование / мемоизация** — сохранение результатов вычислений (ДП).
5. **Два указателя + хеш** — поиск пар с заданной суммой.
6. **Проверка принадлежности** — быстрый поиск в большом наборе.
7. **Отображение координат** — `dict` с ключом-кортежем.

### 1.7. Подводные камни

- **Хеш-коллизии** — разные ключи могут давать одинаковый хеш; Python решает это цепочками, но в худшем случае сложность O(n).
- **Изменяемые ключи** — нельзя использовать `list` как ключ; используйте `tuple`.
- **Порядок обхода** — в Python 3.7+ `dict` сохраняет порядок вставки, но полагаться на это в олимпиадных задачах не стоит.
- **Память** — хеш-таблица занимает больше памяти, чем список.

### Задача 1. Частотный анализ — подсчёт слов (базовый уровень)

**Условие:** Дан текст. Вывести каждое слово и количество его вхождений, отсортировав по убыванию частоты.

**Код с комментариями:**

```python
text = "кот пёс кот кот пёс птица кот птица"
# text — имя переменной
# = — оператор присваивания
# "..." — строковый литерал

words = text.split()
# words — имя переменной (список слов)
# = — присваивание
# text — исходная строка
# .split() — метод разбиения по пробелам
# Результат: ['кот', 'пёс', 'кот', 'кот', 'пёс', 'птица', 'кот', 'птица']

freq = {}
# freq — имя переменной (frequency — частота)
# = — присваивание
# {} — пустой словарь (хеш-таблица)

for word in words:
# for — ключевое слово цикла
# word — переменная-итератор (текущее слово)
# in — принадлежность
# words — список слов
# : — двоеточие

    freq[word] = freq.get(word, 0) + 1
    # freq — словарь
    # [word] — ключ (текущее слово)
    # = — присваивание
    # freq.get — метод безопасного получения значения по ключу
    # (word, 0) — аргументы: ключ и значение по умолчанию (0)
    # + 1 — увеличение на 1
    # Если слова нет — get вернёт 0, станет 1
    # Если есть — get вернёт текущее, станет +1

# Сортируем пары по частоте (убывание)
sorted_freq = sorted(freq.items(), key=lambda x: -x[1])
# sorted_freq — имя переменной (отсортированные пары)
# = — присваивание
# sorted — встроенная функция сортировки
# ( — открывающая скобка
# freq.items() — метод словаря, возвращающий пары (ключ, значение)
# , — разделитель
# key= — именованный аргумент «ключ сортировки»
# lambda — анонимная функция
# x — параметр (пара)
# : — двоеточие
# -x[1] — минус второй элемент (частота) для сортировки по убыванию
# ) — закрывающая скобка

for word, count in sorted_freq:
# for — цикл
# word — слово (первый элемент пары)
# , — разделитель
# count — частота (второй элемент)
# in — принадлежность
# sorted_freq — отсортированный список пар
# : — двоеточие

    print(f"{word}: {count}")
    # print — функция вывода
    # f"..." — f-строка
    # {word} — подстановка слова
    # {count} — подстановка частоты
```

**Результат:**
```
кот: 4
пёс: 2
птица: 2
```

**Сложность:** O(n + k log k), где n — число слов, k — число уникальных.

### Задача 2. Поиск дубликатов и уникальных элементов (базовый уровень)

**Условие:** Дан список чисел. Найти:
- все уникальные элементы;
- все дубликаты;
- есть ли повторяющиеся элементы.

**Код с комментариями:**

```python
numbers = [1, 2, 3, 2, 4, 5, 1, 6, 3, 7]
# numbers — имя переменной (список чисел)
# = — присваивание
# [ — открывающая скобка списка
# 1, 2, 3, ... — элементы
# ] — закрывающая скобка

# Уникальные элементы — множество
unique = set(numbers)
# unique — имя переменной (уникальные)
# = — присваивание
# set(numbers) — преобразование списка во множество
# Множество автоматически удаляет дубликаты

print("Уникальные:", unique)
# print — функция вывода
# "Уникальные:" — текст
# unique — множество
# Результат: {1, 2, 3, 4, 5, 6, 7}

# Дубликаты — элементы, встречающиеся более одного раза
seen = set()
# seen — имя переменной (увиденные)
# = — присваивание
# set() — пустое множество

duplicates = set()
# duplicates — имя переменной (дубликаты)
# = — присваивание
# set() — пустое множество

for num in numbers:
# for — цикл
# num — текущее число
# in numbers — по списку чисел
# : — двоеточие

    if num in seen:
    # if — условный оператор
    # num in seen — проверка наличия в множестве — O(1)
    # : — двоеточие

        duplicates.add(num)
        # duplicates.add — добавление в множество дубликатов
        # (num) — текущее число

    else:
    # else — иначе
    # : — двоеточие

        seen.add(num)
        # seen.add — добавление в множество увиденных

print("Дубликаты:", duplicates)
# print — функция вывода
# "Дубликаты:" — текст
# duplicates — множество
# Результат: {1, 2, 3}

# Проверка наличия дубликатов
has_duplicates = len(numbers) != len(unique)
# has_duplicates — имя переменной (есть ли дубликаты)
# = — присваивание
# len(numbers) != len(unique) — сравнение длин
# Если длины разные — есть дубликаты

print("Есть дубликаты:", has_duplicates)
# print — функция вывода
# "Есть дубликаты:" — текст
# has_duplicates — логическое значение
# Результат: True
```

**Результат:**
```
Уникальные: {1, 2, 3, 4, 5, 6, 7}
Дубликаты: {1, 2, 3}
Есть дубликаты: True
```

**Сложность:** O(n).

### Задача 3. Поиск пары с заданной суммой (средний уровень)

**Условие:** Дан массив `a` и число `target`. Найти **все пары** чисел, дающие в сумме `target`. Пары не должны повторяться.

**Идея:** используем множество `seen` для хранения увиденных чисел. Для каждого `x` проверяем, есть ли `target - x` в `seen`.

**Код с комментариями:**

```python
def find_pairs(a, target):
# def — ключевое слово определения функции
# find_pairs — имя функции
# ( — открывающая скобка параметров
# a — параметр (массив)
# , — разделитель
# target — целевая сумма
# ) — закрывающая скобка
# : — двоеточие

    seen = set()
    # seen — множество увиденных чисел
    # = — присваивание
    # set() — пустое множество

    pairs = set()
    # pairs — множество найденных пар
    # = — присваивание
    # set() — пустое множество

    for x in a:
    # for — цикл по массиву
    # x — текущее число
    # in a — по массиву
    # : — двоеточие

        complement = target - x
        # complement — имя переменной (дополнение)
        # = — присваивание
        # target - x — вычитание

        if complement in seen:
        # if — условный оператор
        # complement in seen — проверка наличия — O(1)
        # : — двоеточие

            # Создаём кортеж-пару в отсортированном порядке
            pair = (min(x, complement), max(x, complement))
            # pair — имя переменной (пара)
            # = — присваивание
            # ( — открывающая скобка кортежа
            # min(x, complement) — меньшее
            # , — разделитель
            # max(x, complement) — большее
            # ) — закрывающая скобка
            # Сортировка нужна, чтобы (2, 7) и (7, 2) считались одной парой

            pairs.add(pair)
            # pairs.add — добавление пары в множество
            # (pair) — кортеж

        seen.add(x)
        # seen.add — добавление текущего числа в увиденные

    return pairs
    # return — возврат множества пар

# Пример
result = find_pairs([2, 7, 11, 15, 3, 6, 8, 1], 9)
# result — имя переменной для результата
# = — присваивание
# find_pairs(...) — вызов функции
# ([2, 7, ...], 9) — аргументы

print("Пары:", sorted(result))
# print — функция вывода
# "Пары:" — текст
# sorted(result) — отсортированное множество пар
# Результат: [(1, 8), (2, 7), (3, 6)]
```

**Результат:**
```
Пары: [(1, 8), (2, 7), (3, 6)]
```

**Сложность:** O(n).

### Задача 4. Группировка анаграмм (средний уровень)

**Условие:** Дан список слов. Сгруппировать слова, являющиеся анаграммами (состоят из одних и тех же букв).

**Идея:** ключ словаря — кортеж отсортированных букв слова.

**Код с комментариями:**

```python
def group_anagrams(words):
# def — определение функции
# group_anagrams — имя функции
# (words) — параметр (список слов)
# : — двоеточие

    groups = {}
    # groups — словарь групп
    # = — присваивание
    # {} — пустой словарь

    for word in words:
    # for — цикл по словам
    # word — текущее слово
    # in words — по списку слов
    # : — двоеточие

        # Ключ — кортеж отсортированных букв
        key = tuple(sorted(word))
        # key — имя переменной (ключ)
        # = — присваивание
        # tuple(sorted(word)) — преобразование отсортированных букв в кортеж
        # sorted(word) — сортировка букв
        # tuple(...) — кортеж (хешируемый!)
        # Пример: "eat" → ('a', 'e', 't')

        if key not in groups:
        # if — условный оператор
        # key not in groups — ключа нет в словаре
        # : — двоеточие

            groups[key] = []
            # groups[key] = [] — создание пустого списка для ключа

        groups[key].append(word)
        # groups[key].append(word) — добавление слова в группу

    return list(groups.values())
    # return — возврат списка групп
    # list(groups.values()) — список значений словаря

# Пример
words = ["eat", "tea", "tan", "ate", "nat", "bat"]
# words — список слов
# = — присваивание

result = group_anagrams(words)
# result — результат

for group in result:
# for — цикл по группам
# group — текущая группа (список слов)
# in result — по списку групп
# : — двоеточие

    print(group)
    # print — функция вывода
    # group — список слов
```

**Результат:**
```
['eat', 'tea', 'ate']
['tan', 'nat']
['bat']
```

**Сложность:** O(n · k log k), где k — средняя длина слова.

### Задача 5. Мемоизация в динамическом программировании (продвинутый уровень)

**Условие:** Вычислить число Фибоначчи `F(n)` с мемоизацией. Сравнить с рекурсией без мемоизации.

**Код с комментариями:**

```python
import time

# Мемоизация через словарь
memo = {}
# memo — имя переменной (memo — память)
# = — присваивание
# {} — пустой словарь (хеш-таблица)

def fib_memo(n):
# def — определение функции
# fib_memo — имя функции
# (n) — параметр
# : — двоеточие

    if n in memo:
    # if — условный оператор
    # n in memo — проверка, есть ли результат в кеше — O(1)
    # : — двоеточие

        return memo[n]
        # return — возврат закешированного результата

    if n <= 1:
    # if — условный оператор
    # n <= 1 — база рекурсии
    # : — двоеточие

        return n
        # return — возврат n (0 или 1)

    result = fib_memo(n - 1) + fib_memo(n - 2)
    # result — имя переменной (результат)
    # = — присваивание
    # fib_memo(n-1) — рекурсивный вызов
    # + — сложение
    # fib_memo(n-2) — рекурсивный вызов

    memo[n] = result
    # memo[n] = result — сохранение в кеш

    return result
    # return — возврат результата

# Рекурсия без мемоизации
def fib_slow(n):
# def — определение функции
# fib_slow — имя функции (медленная)
# (n) — параметр
# : — двоеточие

    if n <= 1:
    # if — условный оператор
    # n <= 1 — база
    # : — двоеточие

        return n
        # return — возврат

    return fib_slow(n - 1) + fib_slow(n - 2)
    # return — возврат суммы двух рекурсивных вызовов

# Замер времени
n = 30
# n — имя переменной
# = — присваивание
# 30 — значение

start = time.time()
# start — имя переменной (старт)
# = — присваивание
# time.time() — текущее время в секундах

print("fib_memo(30) =", fib_memo(n))
# print — функция вывода
# fib_memo(n) — вызов функции с мемоизацией

print("Время (memo):", round(time.time() - start, 6), "сек")
# print — функция вывода
# time.time() - start — разница времени
# round(..., 6) — округление до 6 знаков

start = time.time()
# start — перезапись
# = — присваивание
# time.time() — новое время

print("fib_slow(30) =", fib_slow(n))
# print — функция вывода
# fib_slow(n) — вызов без мемоизации

print("Время (slow):", round(time.time() - start, 6), "сек")
# print — функция вывода
# time.time() - start — разница
```

**Результат (пример):**
```
fib_memo(30) = 832040
Время (memo): 0.000012 сек
fib_slow(30) = 832040
Время (slow): 0.312456 сек
```

**Вывод:** мемоизация через словарь ускоряет вычисления в **тысячи раз**.

**Сложность:** O(n) с мемоизацией, O(2ⁿ) без.

### Задача 6. Хеш-таблица с ключом-кортежем — координаты (продвинутый уровень)

**Условие:** Даны координаты точек. Найти, сколько раз встречается каждая точка. Вывести топ-2.

**Код с комментариями:**

```python
points = [(0, 0), (1, 2), (0, 0), (3, 4), (1, 2), (0, 0)]
# points — имя переменной (список точек)
# = — присваивание
# [ — открывающая скобка списка
# (0, 0) — кортеж-координата
# ... — остальные точки
# ] — закрывающая скобка

counter = {}
# counter — имя переменной (счётчик)
# = — присваивание
# {} — пустой словарь

for point in points:
# for — цикл по точкам
# point — текущая точка (кортеж)
# in points — по списку точек
# : — двоеточие

    counter[point] = counter.get(point, 0) + 1
    # counter — словарь
    # [point] — ключ-кортеж (хешируемый!)
    # = — присваивание
    # counter.get(point, 0) — получение текущего значения (0 если нет)
    # + 1 — увеличение на 1

# Сортируем по частоте (убывание)
sorted_points = sorted(counter.items(), key=lambda x: -x[1])
# sorted_points — отсортированные пары
# = — присваивание
# sorted — сортировка
# ( — открывающая скобка
# counter.items() — пары (точка, частота)
# , — разделитель
# key=lambda x: -x[1] — ключ сортировки: минус частота
# ) — закрывающая скобка

print("Топ-2 точки:")
# print — функция вывода
# "Топ-2 точки:" — текст

for point, count in sorted_points[:2]:
# for — цикл по первым двум
# point — точка
# , — разделитель
# count — частота
# in sorted_points[:2] — срез первых двух пар
# : — двоеточие

    print(f"  {point}: {count} раз")
    # print — функция вывода
    # f"..." — f-строка
    # {point} — подстановка точки
    # {count} — подстановка частоты
```

**Результат:**
```
Топ-2 точки:
  (0, 0): 3 раз
  (1, 2): 2 раз
```

**Ключевой приём:** кортеж хешируем, поэтому может быть ключом словаря. Список — нет.

### Задача 7. Пересечение и объединение множеств (средний уровень)

**Условие:** Даны два списка. Найти:
- общие элементы (пересечение);
- все элементы без повторов (объединение);
- элементы первого, которых нет во втором (разность).

**Код с комментариями:**

```python
a = [1, 2, 3, 4, 5]
# a — первый список
# = — присваивание
# [1, 2, 3, 4, 5] — элементы

b = [4, 5, 6, 7, 8]
# b — второй список
# = — присваивание
# [4, 5, 6, 7, 8] — элементы

set_a = set(a)
# set_a — множество из a
# = — присваивание
# set(a) — преобразование списка в множество

set_b = set(b)
# set_b — множество из b
# = — присваивание
# set(b) — преобразование

print("Пересечение:", set_a & set_b)
# print — функция вывода
# "Пересечение:" — текст
# set_a & set_b — оператор пересечения
# Результат: {4, 5}

print("Объединение:", set_a | set_b)
# "Объединение:" — текст
# set_a | set_b — оператор объединения
# Результат: {1, 2, 3, 4, 5, 6, 7, 8}

print("Разность (a - b):", set_a - set_b)
# "Разность (a - b):" — текст
# set_a - set_b — оператор разности
# Результат: {1, 2, 3}

print("Симметричная разность:", set_a ^ set_b)
# "Симметричная разность:" — текст
# set_a ^ set_b — элементы, которых нет в обоих
# Результат: {1, 2, 3, 6, 7, 8}
```

**Результат:**
```
Пересечение: {4, 5}
Объединение: {1, 2, 3, 4, 5, 6, 7, 8}
Разность (a - b): {1, 2, 3}
Симметричная разность: {1, 2, 3, 6, 7, 8}
```

**Сложность:** O(len(a) + len(b)).

### Задание 6 (продвинутый уровень, 2 балла)

**Условие:** Даны координаты `n` точек. Найдите **максимальное количество точек**, лежащих на одной прямой. Используйте `dict` с ключом — нормализованным направлением (кортежем).

**Подсказка:** для каждой точки `i` считайте направление до всех остальных точек `j` как нормализованный вектор `(dx/g, dy/g)`, где `g = gcd(|dx|, |dy|)`. Ключ — кортеж `(dx/g, dy/g)`. Максимум по словарю + 1 (сама точка).

**Пример:**
```
Ввод: [(1, 1), (2, 2), (3, 3), (4, 5)]
Вывод: 3
```

**Требования:**
- использовать `dict` с ключом-кортежем;
- использовать `math.gcd` для нормализации;
- сложность O(n²);
- обработать вертикальные и горизонтальные линии.
