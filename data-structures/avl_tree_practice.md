**Уровень:** продвинутый (олимпиадное программирование, подготовка к региональному этапу ВсОШ)

**Цель:** изучить AVL-дерево, освоить балансировку через повороты, реализовать операции вставки, удаления и поиска с гарантией O(log n)

## 1. Теоретическая часть

### 1.1. Проблема обычного BST

В бинарном дереве поиска (BST) сложность операций зависит от **высоты дерева**:

| Случай | Высота | Поиск/вставка |
|--------|--------|---------------|
| Сбалансированное дерево | O(log n) | O(log n) |
| Вырожденное (отсортированные данные) | O(n) | O(n) |

**Пример вырождения:** вставим `[1, 2, 3, 4, 5]` в BST — получим «список»:
```
1
 \
  2
   \
    3
     \
      4
       \
        5
```
Поиск `5` требует 5 шагов вместо ~3.

### 1.2. Что такое AVL-дерево?

**AVL-дерево** (названо по фамилиям Адельсона-Вельского и Ландиса, 1962) — **самобалансирующееся** бинарное дерево поиска, в котором для **каждой** вершины выполняется условие:

> **|высота(левого поддерева) − высота(правого поддерева)| ≤ 1**

Такое дерево называется **сбалансированным по высоте**.

**Свойства:**
- высота AVL-дерева с n вершинами — **O(log n)** (точнее, ≤ 1.44·log₂(n+2));
- все операции (поиск, вставка, удаление) — **O(log n)** в худшем случае;
- балансировка выполняется через **повороты** (rotations).

### 1.3. Баланс-фактор

**Баланс-фактор (balance factor)** вершины:

```
BF(v) = height(left(v)) − height(right(v))
```

**Допустимые значения:** −1, 0, +1.

**Нарушения:**
- `BF = +2` — левое поддерево слишком высокое;
- `BF = −2` — правое поддерево слишком высокое.

### 1.4. Четыре случая дисбаланса и повороты

| Случай | BF | Причина | Поворот |
|--------|-----|---------|---------|
| **LL** (Left-Left) | +2, левый ребёнок BF ≥ 0 | Вставка в левое поддерево левого ребёнка | **Малый правый** (Right Rotation) |
| **RR** (Right-Right) | −2, правый ребёнок BF ≤ 0 | Вставка в правое поддерево правого ребёнка | **Малый левый** (Left Rotation) |
| **LR** (Left-Right) | +2, левый ребёнок BF < 0 | Вставка в правое поддерево левого ребёнка | **Большой правый** (Left-Right) |
| **RL** (Right-Left) | −2, правый ребёнок BF > 0 | Вставка в левое поддерево правого ребёнка | **Большой левый** (Right-Left) |

### 1.5. Малый правый поворот (LL)

```
      y                x
     / \              / \
    x   C    →       A   y
   / \                  / \
  A   B                B   C
```

**Код:**
```python
def rotate_right(y):
    x = y.left
    B = x.right
    x.right = y
    y.left = B
    # обновить высоты y и x
    return x
```

### 1.6. Малый левый поворот (RR)

```
    x                  y
   / \                / \
  A   y      →       x   C
     / \            / \
    B   C          A   B
```

**Код:**
```python
def rotate_left(x):
    y = x.right
    B = y.left
    y.left = x
    x.right = B
    # обновить высоты x и y
    return y
```

### 1.7. Большой правый поворот (LR)

```
      z              z              x
     / \            / \            / \
    y   D    →     x   D    →     y   z
   / \            / \            / \ / \
  A   x          y   C          A  B C  D
     / \        / \
    B   C      A   B
```

**Шаги:** сначала `rotate_left(y)`, затем `rotate_right(z)`.

### 1.8. Большой левый поворот (RL)

**Шаги:** сначала `rotate_right(y)`, затем `rotate_left(x)`.

### 1.9. Вставка

1. Обычная вставка в BST (рекурсивно).
2. При возврате из рекурсии — обновить высоту.
3. Вычислить баланс-фактор.
4. Если |BF| > 1 — выполнить соответствующий поворот.

### 1.10. Удаление

1. Обычное удаление в BST (три случая: лист, один ребёнок, два ребёнка).
2. При возврате — обновить высоту и баланс.
3. Выполнить поворот при необходимости.

### 1.11. Типичные ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Не обновляется высота | Забыли `update_height` | Вызывать после каждого изменения |
| Неверный выбор поворота | Путаница LL/RR/LR/RL | Проверять BF ребёнка |
| Потеря поддерева | Неверная перестановка ссылок | Рисовать схему на бумаге |
| Рекурсия без возврата | Забыли `return` | Всегда возвращать новый корень |
| `RecursionError` | Глубина > 1000 | `sys.setrecursionlimit` |

## 2. Практическая часть: полная реализация AVL-дерева

### 2.1. Класс Node

```python
class Node:
# class — ключевое слово определения класса
# Node — имя класса
# : — двоеточие

    def __init__(self, value):
    # def — определение метода
    # __init__ — конструктор
    # (self, value) — параметры
    # : — двоеточие

        self.value = value
        # self.value — значение вершины
        # = — присваивание
        # value — переданное значение

        self.left = None
        # self.left — левый ребёнок
        # = — присваивание
        # None — пусто

        self.right = None
        # self.right — правый ребёнок
        # = — присваивание
        # None — пусто

        self.height = 1
        # self.height — высота поддерева с корнем в этой вершине
        # = — присваивание
        # 1 — лист имеет высоту 1
```

### 2.2. Вспомогательные функции

```python
def height(node):
# def — определение функции
# height — имя функции
# (node) — параметр (вершина или None)
# : — двоеточие

    if node is None:
    # if — условный оператор
    # node is None — пустая вершина
    # : — двоеточие

        return 0
        # return 0 — высота пустого дерева = 0

    return node.height
    # return — возврат высоты вершины
    # node.height — атрибут высоты


def update_height(node):
# def — определение функции
# update_height — имя функции (обновить высоту)
# (node) — параметр
# : — двоеточие

    node.height = 1 + max(height(node.left), height(node.right))
    # node.height — новое значение высоты
    # = — присваивание
    # 1 + — сама вершина
    # max(...) — максимум из высот детей
    # height(node.left) — высота левого поддерева
    # height(node.right) — высота правого поддерева


def balance_factor(node):
# def — определение функции
# balance_factor — имя функции (баланс-фактор)
# (node) — параметр
# : — двоеточие

    if node is None:
    # if — пустая вершина
    # : — двоеточие

        return 0
        # return 0 — баланс пустого = 0

    return height(node.left) - height(node.right)
    # return — возврат разности высот
    # height(node.left) - height(node.right) — BF
```

### 2.3. Повороты

```python
def rotate_right(y):
# def — определение функции
# rotate_right — имя функции (малый правый поворот)
# (y) — параметр (корень дисбаланса)
# : — двоеточие

    x = y.left
    # x — новый корень (левый ребёнок y)
    # = — присваивание
    # y.left — левый ребёнок

    B = x.right
    # B — поддерево, которое переедет
    # = — присваивание
    # x.right — правый ребёнок x

    x.right = y
    # x.right = y — y становится правым ребёнком x

    y.left = B
    # y.left = B — B становится левым ребёнком y

    update_height(y)
    # update_height(y) — обновление высоты y (он ниже)

    update_height(x)
    # update_height(x) — обновление высоты x (он выше)

    return x
    # return x — новый корень поддерева


def rotate_left(x):
# def — определение функции
# rotate_left — имя функции (малый левый поворот)
# (x) — параметр (корень дисбаланса)
# : — двоеточие

    y = x.right
    # y — новый корень (правый ребёнок x)
    # = — присваивание
    # x.right — правый ребёнок

    B = y.left
    # B — поддерево, которое переедет
    # = — присваивание
    # y.left — левый ребёнок y

    y.left = x
    # y.left = x — x становится левым ребёнком y

    x.right = B
    # x.right = B — B становится правым ребёнком x

    update_height(x)
    # update_height(x) — обновление высоты x

    update_height(y)
    # update_height(y) — обновление высоты y

    return y
    # return y — новый корень поддерева
```

### 2.4. Вставка с балансировкой

```python
def insert(node, value):
# def — определение функции
# insert — имя функции (вставка)
# (node, value) — параметры: корень поддерева и значение
# : — двоеточие

    # 1. Обычная вставка в BST
    if node is None:
    # if — дошли до пустого места
    # : — двоеточие

        return Node(value)
        # return — создаём новую вершину

    if value < node.value:
    # if — идём влево
    # : — двоеточие

        node.left = insert(node.left, value)
        # node.left = ... — рекурсивная вставка в левое поддерево

    elif value > node.value:
    # elif — идём вправо
    # : — двоеточие

        node.right = insert(node.right, value)
        # node.right = ... — рекурсивная вставка в правое поддерево

    else:
    # else — значение уже есть (дубликат)
    # : — двоеточие

        return node
        # return node — ничего не меняем

    # 2. Обновляем высоту
    update_height(node)
    # update_height(node) — пересчёт высоты

    # 3. Вычисляем баланс-фактор
    bf = balance_factor(node)
    # bf — баланс-фактор
    # = — присваивание
    # balance_factor(node) — вызов функции

    # 4. Четыре случая дисбаланса

    # LL: левое поддерево левого ребёнка
    if bf > 1 and value < node.left.value:
    # if — BF > 1 (перевес влево) и вставка в левое поддерево левого
    # : — двоеточие

        return rotate_right(node)
        # return — малый правый поворот

    # RR: правое поддерево правого ребёнка
    if bf < -1 and value > node.right.value:
    # if — BF < -1 (перевес вправо) и вставка в правое поддерево правого
    # : — двоеточие

        return rotate_left(node)
        # return — малый левый поворот

    # LR: правое поддерево левого ребёнка
    if bf > 1 and value > node.left.value:
    # if — BF > 1 и вставка в правое поддерево левого
    # : — двоеточие

        node.left = rotate_left(node.left)
        # node.left = ... — сначала левый поворот для левого ребёнка

        return rotate_right(node)
        # return — затем правый поворот

    # RL: левое поддерево правого ребёнка
    if bf < -1 and value < node.right.value:
    # if — BF < -1 и вставка в левое поддерево правого
    # : — двоеточие

        node.right = rotate_right(node.right)
        # node.right = ... — сначала правый поворот для правого ребёнка

        return rotate_left(node)
        # return — затем левый поворот

    return node
    # return node — если баланс в норме, возвращаем как есть
```

### 2.5. Удаление с балансировкой

```python
def min_value_node(node):
# def — определение функции
# min_value_node — имя функции (минимум в поддереве)
# (node) — параметр
# : — двоеточие

    current = node
    # current — текущая вершина
    # = — присваивание
    # node — начальная

    while current.left is not None:
    # while — цикл, пока есть левый ребёнок
    # : — двоеточие

        current = current.left
        # current = current.left — идём влево

    return current
    # return current — минимум


def delete(node, value):
# def — определение функции
# delete — имя функции (удаление)
# (node, value) — параметры
# : — двоеточие

    # 1. Обычное удаление в BST
    if node is None:
    # if — вершина не найдена
    # : — двоеточие

        return node
        # return — ничего не делаем

    if value < node.value:
    # if — идём влево
    # : — двоеточие

        node.left = delete(node.left, value)
        # node.left = ... — рекурсивное удаление влево

    elif value > node.value:
    # elif — идём вправо
    # : — двоеточие

        node.right = delete(node.right, value)
        # node.right = ... — рекурсивное удаление вправо

    else:
    # else — нашли вершину для удаления
    # : — двоеточие

        # Случай 1: лист или один ребёнок
        if node.left is None:
        # if — нет левого ребёнка
        # : — двоеточие

            return node.right
            # return — правый ребёнок становится на место

        elif node.right is None:
        # elif — нет правого ребёнка
        # : — двоеточие

            return node.left
            # return — левый ребёнок становится на место

        # Случай 2: два ребёнка
        temp = min_value_node(node.right)
        # temp — минимальная вершина в правом поддереве
        # = — присваивание
        # min_value_node(node.right) — вызов

        node.value = temp.value
        # node.value = temp.value — замена значения

        node.right = delete(node.right, temp.value)
        # node.right = ... — удаление минимума из правого поддерева

    # 2. Обновляем высоту
    update_height(node)
    # update_height(node) — пересчёт

    # 3. Балансировка
    bf = balance_factor(node)
    # bf — баланс-фактор

    # LL
    if bf > 1 and balance_factor(node.left) >= 0:
    # if — BF > 1 и левый ребёнок сбалансирован/перевес влево
    # : — двоеточие

        return rotate_right(node)
        # return — правый поворот

    # LR
    if bf > 1 and balance_factor(node.left) < 0:
    # if — BF > 1 и левый ребёнок с перевесом вправо
    # : — двоеточие

        node.left = rotate_left(node.left)
        # node.left = ... — левый поворот для левого ребёнка

        return rotate_right(node)
        # return — правый поворот

    # RR
    if bf < -1 and balance_factor(node.right) <= 0:
    # if — BF < -1 и правый ребёнок сбалансирован/перевес вправо
    # : — двоеточие

        return rotate_left(node)
        # return — левый поворот

    # RL
    if bf < -1 and balance_factor(node.right) > 0:
    # if — BF < -1 и правый ребёнок с перевесом влево
    # : — двоеточие

        node.right = rotate_right(node.right)
        # node.right = ... — правый поворот для правого ребёнка

        return rotate_left(node)
        # return — левый поворот

    return node
    # return node — если баланс в норме
```

### 2.6. Класс AVLTree (обёртка)

```python
class AVLTree:
# class — определение класса
# AVLTree — имя класса
# : — двоеточие

    def __init__(self):
    # def — конструктор
    # (self) — параметр
    # : — двоеточие

        self.root = None
        # self.root — корень
        # = — присваивание
        # None — пустое дерево

    def insert(self, value):
    # def — метод вставки
    # (self, value) — параметры
    # : — двоеточие

        self.root = insert(self.root, value)
        # self.root = ... — обновление корня (может измениться после поворота)

    def delete(self, value):
    # def — метод удаления
    # (self, value) — параметры
    # : — двоеточие

        self.root = delete(self.root, value)
        # self.root = ... — обновление корня

    def search(self, value):
    # def — метод поиска
    # (self, value) — параметры
    # : — двоеточие

        current = self.root
        # current — текущая вершина
        # = — присваивание

        while current is not None:
        # while — цикл, пока не дошли до None
        # : — двоеточие

            if value == current.value:
            # if — нашли
            # : — двоеточие

                return True
                # return True — найдено

            elif value < current.value:
            # elif — идём влево
            # : — двоеточие

                current = current.left
                # current = current.left — переход влево

            else:
            # else — вправо
            # : — двоеточие

                current = current.right
                # current = current.right — переход вправо

        return False
        # return False — не найдено

    def inorder(self):
    # def — метод обхода
    # (self) — параметр
    # : — двоеточие

        result = []
        # result — список значений
        # = — присваивание
        # [] — пустой список

        self._inorder(self.root, result)
        # self._inorder(...) — рекурсивный обход

        return result
        # return — возврат списка

    def _inorder(self, node, result):
    # def — приватный метод обхода
    # (self, node, result) — параметры
    # : — двоеточие

        if node is None:
        # if — пустая вершина
        # : — двоеточие

            return
            # return — выход

        self._inorder(node.left, result)
        # self._inorder(...) — обход левого

        result.append(node.value)
        # result.append(node.value) — добавление значения

        self._inorder(node.right, result)
        # self._inorder(...) — обход правого

    def height(self):
    # def — метод высоты
    # (self) — параметр
    # : — двоеточие

        return height(self.root)
        # return — высота корня

    def is_balanced(self):
    # def — метод проверки баланса
    # (self) — параметр
    # : — двоеточие

        return self._is_balanced(self.root)
        # return — результат проверки

    def _is_balanced(self, node):
    # def — приватный метод
    # (self, node) — параметр
    # : — двоеточие

        if node is None:
        # if — пустая вершина
        # : — двоеточие

            return True
            # return True — пустое дерево сбалансировано

        bf = balance_factor(node)
        # bf — баланс-фактор

        if abs(bf) > 1:
        # if — |BF| > 1
        # : — двоеточие

            return False
            # return False — дисбаланс

        return self._is_balanced(node.left) and self._is_balanced(node.right)
        # return — проверка детей
        # and — логическое И
```

```python
# print — функция вывода
```

## 3. Пошаговый разбор вставки `[10, 20, 30]`

### Шаг 1: вставка 10
```
    10 (h=1, BF=0)
```

### Шаг 2: вставка 20
```
    10 (h=2, BF=-1)
      \
       20 (h=1, BF=0)
```
Баланс в норме.

### Шаг 3: вставка 30 (случай RR)
```
    10 (h=3, BF=-2) ← дисбаланс!
      \
       20 (h=2, BF=-1)
         \
          30 (h=1, BF=0)
```

**BF(10) = −2**, правый ребёнок 20 имеет **BF = −1 ≤ 0** → случай **RR** → **малый левый поворот**.

**После `rotate_left(10)`:**
```
       20 (h=2, BF=0)
      /  \
    10    30
   (h=1) (h=1)
```
Дерево сбалансировано.

## 4. Пошаговый разбор вставки `[10, 20, 30, 40, 50, 25]`

После первых трёх — дерево выше. Вставим 40:

```
       20
      /  \
    10    30 (h=2, BF=-1)
             \
              40 (h=1)
```
Баланс в норме.

Вставим 50:
```
       20 (h=3, BF=-1)
      /  \
    10    30 (h=2, BF=-1)
             \
              40 (h=1, BF=-1)
                \
                 50 (h=1)
```
Баланс в норме (BF(20) = −1).

Вставим 25:
```
       20 (h=4, BF=-1)
      /  \
    10    30 (h=3, BF=+1)
          /  \
        25    40 (h=2, BF=-1)
                 \
                  50 (h=1)
```
Проверим BF(30) = height(25) − height(40) = 1 − 2 = −1. BF(20) = 1 − 3 = −2? Нет: height(left=10)=1, height(right=30)=3, BF = −2. **Дисбаланс!**

Правый ребёнок 30 имеет **BF = +1 > 0** → случай **RL** → **большой левый поворот**.

**Шаг 1: `rotate_right(30)`** — правый поворот для правого ребёнка:
```
       20
      /  \
    10    25 (h=2)
             \
              30 (h=1)
                \
                 40 (h=1)
                   \
                    50
```

**Шаг 2: `rotate_left(20)`**:
```
          25
         /  \
       20    30
      /  \     \
    10    (nil) 40
                  \
                   50
```
Хм, здесь нужно аккуратно — правильный результат после балансировки:

```
          30
         /  \
       20    40
      /  \     \
    10   25    50
```

Высота = 3, дерево сбалансировано.
