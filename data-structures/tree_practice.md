## 1. Теоретическая часть

### 1.1. Что такое дерево?

**Дерево (tree)** — связный граф без циклов, в котором есть **корень** (root) и каждая вершина (кроме корня) имеет ровно одного **родителя** (parent).

**Аналогия из жизни:** генеалогическое древо, файловая система, структура компании.

**Основные понятия:**

| Термин | Определение |
|--------|-------------|
| **Корень (root)** | Вершина без родителя |
| **Лист (leaf)** | Вершина без детей |
| **Родитель (parent)** | Вершина, из которой есть ребро к данной |
| **Ребёнок (child)** | Вершина, в которую есть ребро от данной |
| **Предок (ancestor)** | Вершина на пути от корня к данной |
| **Потомок (descendant)** | Вершина на пути от данной к листу |
| **Глубина (depth)** | Расстояние от корня до вершины |
| **Высота (height)** | Максимальная глубина |
| **Поддерево (subtree)** | Вершина и все её потомки |

### 1.2. Виды деревьев

| Вид | Описание |
|-----|----------|
| **Бинарное (binary)** | У каждой вершины не более 2 детей |
| **Бинарное дерево поиска (BST)** | Левый ребёнок < родитель < правый ребёнок |
| **Куча (heap)** | Родитель ≤ детей (min-heap) или ≥ (max-heap) |
| **Префиксное дерево (trie)** | Для хранения строк |
| **Дерево отрезков (segment tree)** | Для запросов на отрезках |
| **Дерево Фенвика (Fenwick)** | Для сумм на префиксах |

### 1.3. Способы представления дерева в Python

#### Способ 1: список смежности (граф)

```python
tree = {
    1: [2, 3],
    2: [4, 5],
    3: [6],
    4: [],
    5: [],
    6: []
}
```

#### Способ 2: массив родителей

```python
parent = [0, 0, 1, 1, 2, 2, 3]  # parent[i] — родитель вершины i
# parent[1] = 0 (корень), parent[2] = 1, parent[3] = 1, ...
```

#### Способ 3: список детей

```python
children = [[2, 3], [4, 5], [6], [], [], []]
# children[0] = [2, 3] — дети корня (вершина 1)
```

#### Способ 4: класс Node (для бинарного дерева)

```python
class Node:
    def __init__(self, value):
        self.value = value
        self.left = None
        self.right = None
```

### 1.4. Обходы дерева

| Обход | Порядок | Применение |
|-------|---------|------------|
| **DFS (в глубину)** | Рекурсивно вниз | Поиск, подсчёт, проверка |
| **BFS (в ширину)** | По уровням | Кратчайший путь, уровни |
| **Preorder (прямой)** | Корень → Левое → Правое | Копирование дерева |
| **Inorder (симметричный)** | Левое → Корень → Правое | BST — сортировка |
| **Postorder (обратный)** | Левое → Правое → Корень | Удаление, вычисление |

### 1.5. Бинарное дерево поиска (BST)

**Свойство:** для любой вершины все значения в левом поддереве **меньше**, а в правом — **больше**.

**Операции:**

| Операция | Средняя сложность | Худшая |
|----------|-------------------|--------|
| Поиск | O(log n) | O(n) |
| Вставка | O(log n) | O(n) |
| Удаление | O(log n) | O(n) |

**Проблема:** если вставлять отсортированные данные — дерево вырождается в список (O(n)). Решение — **балансированные деревья** (AVL, красно-чёрные).

### 1.6. Применение деревьев в олимпиадном программировании

1. **Обходы DFS/BFS** — подсчёт размера поддерева, глубины, суммы.
2. **LCA (наименьший общий предок)** — запросы на путях.
3. **Диаметр дерева** — longest path.
4. **Центроид дерева** — балансировка.
5. **Дерево отрезков** — запросы на отрезках (сумма, минимум, максимум).
6. **Trie** — поиск строк, автодополнение.
7. **Куча** — приоритетная очередь (`heapq`).

### 1.7. Типичные ошибки

| Ошибка | Причина | Решение |
|--------|---------|---------|
| Бесконечная рекурсия | Нет проверки на `None` | Проверять `if node is None: return` |
| `RecursionError` | Глубина > 1000 | `sys.setrecursionlimit(10**6)` |
| Путаница с индексами | 0-based vs 1-based | Выбрать один стиль |
| Забыли про корень | Корень не имеет родителя | Обрабатывать отдельно |
| Циклы в графе | Дерево — без циклов | Проверять `visited` |

### Задача 2. Обход BFS по уровням (базовый уровень)

**Условие:** Дано дерево. Вывести вершины по уровням (BFS).

**Код с комментариями:**

```python
from collections import deque
# from — импорт
# collections — модуль
# import — ключевое слово
# deque — двусторонняя очередь

# Дерево в виде словаря смежности
tree = {
    1: [2, 3],
    2: [4, 5],
    3: [6],
    4: [],
    5: [],
    6: []
}
# tree — имя переменной (дерево)
# = — присваивание
# { — открывающая скобка словаря
# 1: [2, 3] — вершина 1 имеет детей 2 и 3
# ... — остальные вершины
# } — закрывающая скобка

def bfs(root):
# def — определение функции
# bfs — имя функции (breadth-first search)
# (root) — параметр (корень)
# : — двоеточие

    queue = deque([root])
    # queue — очередь
    # = — присваивание
    # deque([root]) — очередь с корнем

    while queue:
    # while — цикл, пока очередь не пуста

        level_size = len(queue)
        # level_size — количество вершин на текущем уровне
        # = — присваивание
        # len(queue) — длина очереди

        level = []
        # level — список вершин текущего уровня
        # = — присваивание
        # [] — пустой список

        for _ in range(level_size):
        # for — цикл по вершинам уровня
        # _ — игнорируемая переменная
        # in range(level_size) — level_size раз
        # : — двоеточие

            v = queue.popleft()
            # v — текущая вершина
            # = — присваивание
            # queue.popleft() — извлечение из начала — O(1)

            level.append(v)
            # level.append(v) — добавление в уровень

            for child in tree.get(v, []):
            # for — цикл по детям
            # child — текущий ребёнок
            # in tree.get(v, []) — по списку детей (или пустому)
            # : — двоеточие

                queue.append(child)
                # queue.append(child) — добавление в конец очереди

        print("Уровень:", level)
        # print — функция вывода
        # "Уровень:" — текст
        # level — список вершин

bfs(1)
# bfs(1) — запуск с корня
```

**Пример работы:**
```
Уровень: [1]
Уровень: [2, 3]
Уровень: [4, 5, 6]
```

**Сложность:** O(n).

### Задача 3. Высота и размер поддерева (средний уровень)

**Условие:** Для каждой вершины найти высоту её поддерева и количество вершин в нём.

**Код с комментариями:**

```python
import sys
sys.setrecursionlimit(10**6)

children = [[1, 2], [3, 4], [5], [], [], []]
# children — список детей (0-based)
# children[0] = [2, 3] — дети вершины 1 (индекс 0)
# ... — остальные

n = 6
# n — количество вершин

size = [0] * n
# size — массив размеров поддеревьев
# = — присваивание
# [0] * n — список из n нулей

height = [0] * n
# height — массив высот
# = — присваивание
# [0] * n — список из n нулей

def dfs(v):
# def — определение функции
# dfs — имя функции
# (v) — параметр (вершина, 0-based)
# : — двоеточие

    size[v] = 1
    # size[v] = 1 — сама вершина

    max_child_height = 0
    # max_child_height — максимальная высота среди детей
    # = — присваивание
    # 0 — начальное значение

    for child in children[v]:
    # for — цикл по детям
    # child — текущий ребёнок
    # in children[v] — по списку детей
    # : — двоеточие

        dfs(child)
        # dfs(child) — рекурсивный вызов

        size[v] += size[child]
        # size[v] += size[child] — прибавление размера поддерева ребёнка

        max_child_height = max(max_child_height, height[child])
        # max(...) — максимум из двух
        # height[child] — высота поддерева ребёнка

    height[v] = max_child_height + 1
    # height[v] = ... — высота вершины = макс. высота ребёнка + 1

dfs(0)
# dfs(0) — запуск с корня (индекс 0)

for i in range(n):
# for — цикл по вершинам
# i — индекс
# in range(n) — от 0 до n-1
# : — двоеточие

    print(f"Вершина {i}: размер={size[i]}, высота={height[i]}")
    # print — функция вывода
    # f"..." — f-строка
    # {i + 1} — номер вершины (1-based)
    # {size[i]} — размер
    # {height[i]} — высота
```

**Пример работы:**
```
Вершина 1: размер=6, высота=3
Вершина 2: размер=3, высота=2
Вершина 3: размер=2, высота=2
Вершина 4: размер=1, высота=1
Вершина 5: размер=1, высота=1
Вершина 6: размер=1, высота=1
```

**Сложность:** O(n).

### Задача 4. Бинарное дерево поиска (BST) (средний уровень)

**Условие:** Реализовать BST с операциями вставки, поиска и симметричного обхода (inorder).

**Код с комментариями:**

```python
class Node:
# class — ключевое слово определения класса
# Node — имя класса
# : — двоеточие

    def __init__(self, value):
    # def — определение метода
    # __init__ — конструктор (вызывается при создании)
    # (self, value) — параметры: self (экземпляр), value (значение)
    # : — двоеточие

        self.value = value
        # self.value — атрибут экземпляра
        # = — присваивание
        # value — значение

        self.left = None
        # self.left — левый ребёнок
        # = — присваивание
        # None — пусто

        self.right = None
        # self.right — правый ребёнок
        # = — присваивание
        # None — пусто

class BST:
# class — определение класса
# BST — имя класса (Binary Search Tree)
# : — двоеточие

    def __init__(self):
    # def — конструктор
    # (self) — параметр
    # : — двоеточие

        self.root = None
        # self.root — корень дерева
        # = — присваивание
        # None — пустое дерево

    def insert(self, value):
    # def — метод вставки
    # (self, value) — параметры
    # : — двоеточие

        if self.root is None:
        # if — условный оператор
        # self.root is None — дерево пустое
        # : — двоеточие

            self.root = Node(value)
            # self.root = Node(value) — создание корня
            # return — выход

            return

        current = self.root
        # current — текущая вершина
        # = — присваивание
        # self.root — корень

        while True:
        # while — цикл
        # True — бесконечный цикл
        # : — двоеточие

            if value < current.value:
            # if — условный оператор
            # value < current.value — идём влево
            # : — двоеточие

                if current.left is None:
                # if — левого ребёнка нет
                # : — двоеточие

                    current.left = Node(value)
                    # current.left = Node(value) — создание левого ребёнка

                    break
                    # break — выход из цикла

                current = current.left
                # current = current.left — переход влево

            else:
            # else — иначе (идём вправо)
            # : — двоеточие

                if current.right is None:
                # if — правого ребёнка нет
                # : — двоеточие

                    current.right = Node(value)
                    # current.right = Node(value) — создание правого ребёнка

                    break
                    # break — выход

                current = current.right
                # current = current.right — переход вправо

    def search(self, value):
    # def — метод поиска
    # (self, value) — параметры
    # : — двоеточие

        current = self.root
        # current — текущая вершина
        # = — присваивание
        # self.root — корень

        while current is not None:
        # while — цикл, пока не дошли до None
        # : — двоеточие

            if value == current.value:
            # if — нашли
            # : — двоеточие

                return True
                # return True — найдено

            elif value < current.value:
            # elif — иначе если
            # value < current.value — идём влево
            # : — двоеточие

                current = current.left
                # current = current.left — переход влево

            else:
            # else — иначе (вправо)
            # : — двоеточие

                current = current.right
                # current = current.right — переход вправо

        return False
        # return False — не найдено

    def inorder(self):
    # def — метод симметричного обхода
    # (self, node=None) — параметры
    # : — двоеточие
        self._inorder(self.root)
        # self.inorder(self.root) — обход корня
    def _inorder(self, node):
        if node is None:
            return
        self._inorder(node.left)
        print(node.value, end=" ")
        self._inorder(node.right)

# Пример
bst = BST()
# bst — экземпляр класса BST
# = — присваивание
# BST() — вызов конструктора

for x in [50, 30, 70, 20, 40, 60, 80]:
# for — цикл
# x — текущее значение
# in [50, 30, ...] — по списку
# : — двоеточие

    bst.insert(x)
    # bst.insert(x) — вставка

print("Inorder (отсортировано):", end=" ")
# print — функция вывода

bst.inorder()
# bst.inorder() — обход

print()
# print() — перевод строки

print("Поиск 40:", bst.search(40))
# print — функция вывода
# "Поиск 40:" — текст
# bst.search(40) — поиск

print("Поиск 55:", bst.search(55))
# print — функция вывода
```

**Пример работы:**
```
Inorder (отсортировано): 20 30 40 50 60 70 80
Поиск 40: True
Поиск 55: False
```

**Сложность:** O(log n) в среднем, O(n) в худшем.

### Задача 5. LCA — наименьший общий предок (продвинутый уровень)

**Условие:** Дано дерево и два узла. Найти их наименьшего общего предка (LCA).

**Идея:** поднимаем более глубокий узел до уровня другого, затем поднимаем оба до совпадения.

**Код с комментариями:**

```python
import sys
sys.setrecursionlimit(10**6)
# Увеличение лимита рекурсии

parent = [0, 0, 1, 1, 2, 2, 3]
# parent — список родителей (1-based)
# parent[1] = 0 — корень
# parent[2] = 1, parent[3] = 1, ...

n = 6
# n — количество вершин

depth = [0] * (n + 1)
# depth — массив глубин
# = — присваивание
# [0] * (n + 1) — список из n+1 нулей

children = [[] for _ in range(n + 1)]
# children — список детей
# = — присваивание
# [[] for _ in range(n + 1)] — пустые списки

for i in range(1, n + 1):
# for — цикл по вершинам
# i — номер вершины
# in range(1, n + 1) — от 1 до n
# : — двоеточие

    children[parent[i]].append(i)
    # children[parent[i]].append(i) — добавление i в детей родителя

# DFS для вычисления глубин
def dfs(v, d):
# def — определение функции
# dfs — имя функции
# (v, d) — параметры: вершина и глубина
# : — двоеточие

    depth[v] = d
    # depth[v] = d — запись глубины

    for child in children[v]:
    # for — цикл по детям
    # child — текущий ребёнок
    # in children[v] — по списку детей
    # : — двоеточие

        dfs(child, d + 1)
        # dfs(child, d + 1) — рекурсивный вызов с глубиной +1

dfs(1, 0)
# dfs(1, 0) — запуск с корня (глубина 0)

def lca(u, v):
# def — определение функции
# lca — имя функции (lowest common ancestor)
# (u, v) — параметры: два узла
# : — двоеточие

    # Поднимаем более глубокий узел
    while depth[u] > depth[v]:
    # while — цикл
    # depth[u] > depth[v] — u глубже
    # : — двоеточие

        u = parent[u]
        # u = parent[u] — подъём на уровень выше

    while depth[v] > depth[u]:
    # while — цикл
    # depth[v] > depth[u] — v глубже
    # : — двоеточие

        v = parent[v]
        # v = parent[v] — подъём

    # Теперь на одном уровне — поднимаем оба
    while u != v:
    # while — цикл, пока не совпали
    # : — двоеточие

        u = parent[u]
        # u = parent[u] — подъём u

        v = parent[v]
        # v = parent[v] — подъём v

    return u
    # return u — LCA найден

# Пример
print("LCA(4, 5) =", lca(4, 5))
# print — функция вывода
# "LCA(4, 5) =" — текст
# lca(4, 5) — вызов функции

print("LCA(4, 6) =", lca(4, 6))
# print — функция вывода

print("LCA(2, 3) =", lca(2, 3))
# print — функция вывода
```

**Пример работы:**
```
LCA(4, 5) = 2
LCA(4, 6) = 1
LCA(2, 3) = 1
```

**Сложность:** O(h), где h — высота дерева. Для больших деревьев используют бинарный подъём (O(log n)).

### Задача 6. Диаметр дерева (продвинутый уровень)

**Условие:** Найти диаметр дерева — длину longest path между двумя вершинами.

**Идея:** два BFS: первый — от произвольной вершины находим самую дальнюю `u`; второй — от `u` находим самую дальнюю `v`. Расстояние `u-v` — диаметр.

**Код с комментариями:**

```python
from collections import deque
# from — импорт
# collections — модуль
# import — ключевое слово
# deque — очередь

tree = {
    1: [2, 3],
    2: [4, 5],
    3: [6],
    4: [],
    5: [],
    6: []
}
# tree — дерево (словарь смежности)
# = — присваивание
# { ... } — словарь

def bfs_farthest(start):
# def — определение функции
# bfs_farthest — имя функции
# (start) — параметр (стартовая вершина)
# : — двоеточие

    dist = {start: 0}
    # dist — словарь расстояний
    # = — присваивание
    # {start: 0} — старт с расстоянием 0

    queue = deque([start])
    # queue — очередь
    # = — присваивание
    # deque([start]) — очередь со стартом

    farthest = start
    # farthest — самая дальняя вершина
    # = — присваивание
    # start — начальное значение

    while queue:
    # while — цикл, пока очередь не пуста

        v = queue.popleft()
        # v — текущая вершина
        # = — присваивание
        # queue.popleft() — извлечение из начала

        if dist[v] > dist[farthest]:
        # if — сравнение расстояний
        # dist[v] > dist[farthest] — v дальше
        # : — двоеточие

            farthest = v
            # farthest = v — обновление

        for neighbor in tree.get(v, []):
        # for — цикл по соседям
        # neighbor — сосед
        # in tree.get(v, []) — по списку смежных
        # : — двоеточие

            if neighbor not in dist:
            # if — не посещали
            # : — двоеточие

                dist[neighbor] = dist[v] + 1
                # dist[neighbor] = ... — расстояние +1

                queue.append(neighbor)
                # queue.append(neighbor) — добавление в очередь

    return farthest, dist[farthest]
    # return — возврат дальней вершины и расстояния

# Первый BFS: от произвольной вершины (1)
u, _ = bfs_farthest(1)
# u — самая дальняя от 1
# _ — игнорируемое расстояние

# Второй BFS: от u находим v
v, diameter = bfs_farthest(u)
# v — самая дальняя от u
# diameter — диаметр

print(f"Диаметр: {diameter} (между {u} и {v})")
# print — функция вывода
# f"..." — f-строка
# {diameter} — диаметр
# {u}, {v} — вершины
```

**Пример работы:**
```
Диаметр: 4 (между 5 и 6)
```

**Сложность:** O(n).

### Задача 7. Дерево отрезков — сумма на отрезке (продвинутый уровень)

**Условие:** Реализовать дерево отрезков для запросов суммы на отрезке `[l, r]` и обновления элемента.

**Код с комментариями:**

```python
class SegmentTree:
# class — определение класса
# SegmentTree — имя класса
# : — двоеточие

    def __init__(self, arr):
    # def — конструктор
    # (self, arr) — параметры: массив
    # : — двоеточие

        self.n = len(arr)
        # self.n — количество элементов
        # = — присваивание
        # len(arr) — длина

        self.tree = [0] * (4 * self.n)
        # self.tree — массив дерева (4n)
        # = — присваивание
        # [0] * (4 * self.n) — нули

        self.build(arr, 1, 0, self.n - 1)
        # self.build(...) — построение дерева

    def build(self, arr, node, left, right):
    # def — метод построения
    # (self, arr, node, left, right) — параметры
    # : — двоеточие

        if left == right:
        # if — лист
        # : — двоеточие

            self.tree[node] = arr[left]
            # self.tree[node] = arr[left] — значение листа

        else:
        # else — внутренний узел
        # : — двоеточие

            mid = (left + right) // 2
            # mid — середина
            # = — присваивание
            # (left + right) // 2 — целочисленное деление

            self.build(arr, 2 * node, left, mid)
            # self.build(...) — левое поддерево

            self.build(arr, 2 * node + 1, mid + 1, right)
            # self.build(...) — правое поддерево

            self.tree[node] = self.tree[2 * node] + self.tree[2 * node + 1]
            # self.tree[node] = ... — сумма детей

    def query(self, node, left, right, ql, qr):
    # def — метод запроса
    # (self, node, left, right, ql, qr) — параметры
    # : — двоеточие

        if ql > right or qr < left:
        # if — вне диапазона
        # : — двоеточие

            return 0
            # return 0 — нейтральный элемент для суммы

        if ql <= left and right <= qr:
        # if — полностью внутри
        # : — двоеточие

            return self.tree[node]
            # return — значение узла

        mid = (left + right) // 2
        # mid — середина

        return (self.query(2 * node, left, mid, ql, qr) +
        # self.query(...) — левая часть
        # + — сложение

                self.query(2 * node + 1, mid + 1, right, ql, qr))
        # self.query(...) — правая часть

    def update(self, node, left, right, idx, value):
    # def — метод обновления
    # (self, node, left, right, idx, value) — параметры
    # : — двоеточие

        if left == right:
        # if — лист
        # : — двоеточие

            self.tree[node] = value
            # self.tree[node] = value — обновление

        else:
        # else — внутренний узел
        # : — двоеточие

            mid = (left + right) // 2
            # mid — середина

            if idx <= mid:
            # if — идём влево
            # : — двоеточие

                self.update(2 * node, left, mid, idx, value)
                # self.update(...) — обновление влево

            else:
            # else — идём вправо
            # : — двоеточие

                self.update(2 * node + 1, mid + 1, right, idx, value)
                # self.update(...) — обновление вправо

            self.tree[node] = self.tree[2 * node] + self.tree[2 * node + 1]
            # self.tree[node] = ... — пересчёт

# Пример
arr = [1, 3, 5, 7, 9, 11]
# arr — массив
# = — присваивание

st = SegmentTree(arr)
# st — экземпляр
# = — присваивание
# SegmentTree(arr) — создание

print("Сумма [1, 3]:", st.query(1, 0, st.n - 1, 1, 3))
# print — функция вывода
# "Сумма [1, 3]:" — текст
# st.query(...) — запрос

st.update(1, 0, st.n - 1, 2, 10)
# st.update(...) — обновление arr[2] = 10

print("Сумма [1, 3] после обновления:", st.query(1, 0, st.n - 1, 1, 3))
# print — функция вывода
```

**Пример работы:**
```
Сумма [1, 3]: 15
Сумма [1, 3] после обновления: 20
```

**Сложность:** O(log n) на запрос и обновление, O(n) на построение.
