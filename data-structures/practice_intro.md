## Часть 3. Переменные и ввод данных (20 минут)

### Теория

**Переменная** — это «ящик» для хранения значения .

```python
name = "Иван"      # строка (str)
age = 15            # целое число (int)
height = 1.75       # дробное число (float)
```

**Ввод данных** — команда `input()`:

```python
name = input("Как тебя зовут? ")
print("Привет, " + name + "!")
```

### Программа «Знакомство»

Создайте `znakomstvo.py`:

```python
print("Давай познакомимся!")

name = input("Как тебя зовут? ")
age = input("Сколько тебе лет? ")

print("Привет, " + name + "!")
print("Тебе " + age + " лет.")
```

**Запуск:**
```bash
python3 znakomstvo.py
```

> ⚠️ **Важно:** `input()` всегда возвращает **строку**. Если нужно число, используйте `int(input(...))` или `float(input(...))` .

### Программа «Калькулятор»

Создайте `calc.py`:

```python
a = int(input("Введите первое число: "))
b = int(input("Введите второе число: "))

print("Сумма:", a + b)
print("Разность:", a - b)
print("Произведение:", a * b)
print("Деление:", a / b)
```

## Часть 4. Условия: if / else (20 минут)

### Теория

```python
if условие:
    # выполнить, если истина
else:
    # выполнить, если ложь
```

### Пример: проверка чётности

```python
number = int(input("Введите число: "))

if number % 2 == 0:

else:
    print("Число нечётное")
```

## Часть 5. Запуск как исполняемого файла (15 минут)

### Зачем это нужно

Вместо `python3 script.py` можно запускать просто `./script.py` — как обычную программу.

### Шаг 1. Добавить shebang

Первая строка файла:

```python
#!/usr/bin/env python3
print("Программа запускается напрямую!")
```

### Шаг 2. Дать право на выполнение

```bash
chmod +x script.py
```

### Шаг 3. Запустить

```bash
./script.py
```

Точка и слэш `./` обязательны — они означают «искать файл в текущей папке» .

## Часть 6. Мини-проект: «Угадай число» (10 минут)

Соберите всё вместе. Создайте `game.py`:

```python
#!/usr/bin/env python3

secret = 7

print("Я загадал число от 1 до 10.")
guess = int(input("Твой вариант: "))

if guess == secret:
    print("Правильно! Ты угадал!")
else:
    print("Не угадал. Я загадал", secret)
```

**Задание 6 (дополнительно).** Сделайте число случайным:


## Частые ошибки

| Ошибка | Причина | Решение |
|---|---|---|
| `SyntaxError` | Опечатка в коде | Проверьте строку, которую указывает Python |
| `NameError` | Переменная не создана | Проверьте имя переменной |
| `IndentationError` | Неправильные отступы | В Python отступы обязательны (4 пробела) |
| `ValueError` | `int()` получил не число | Введите только цифры |
| `Permission denied` | Нет права на запуск | `chmod +x file.py` |
